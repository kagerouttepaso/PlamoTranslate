# PLaMo翻訳（Android）

端末の中だけで動くAndroidの翻訳アプリです。翻訳にはPreferred NetworksのPLaMo 3 Translate（GGUF、Q4_K_M）を使い、llama.cppで端末上で推論します。モデルを最初にダウンロードした後は、翻訳中に通信しません。設定の画面で「更新を確認」を押したときだけ、GitHubに新しい版があるかを確かめます。

| 機能 | 内容 |
| --- | --- |
| 会話翻訳 | 開始するとマイクを入れたままにし、日本語・韓国語・英語・中国語などの発話を認識して、話している最中から途中訳を、話し終わると確定訳を出す。表示は対面（上半分が相手向け）と1画面を選べ、会話ログを共有・保存できる |
| カメラ翻訳 | 看板・メニュー・ラベルにカメラを向けると、読めた文字の上に訳を重ねる。文章（段落にまとめる）と表・メニュー（1行ずつ）を切り替えられ、タップで一時停止して読める |
| 画面翻訳 | 浮遊ボタンを押すと（または画面が止まったら自動で）画面を撮って文字を認識し、訳文を元の位置に重ねる。中国語・韓国語・英語の原文を自動で判定し、縦書きの漫画は縦書きの日本語で訳す。ゲーム向けの認識モード、訳を吹き出しいっぱいに広げる表示を浮遊ボタンの長押しで選べる。一度訳した文は端末に控え、次から即座に出す |
| テキスト翻訳 | 入力欄に入れた文を訳す。PLaMoが扱う53言語に対応し、原文を音声でも入れられる |
| 読み上げ | 会話翻訳のカードの訳文をタップ、テキスト翻訳の🔊で訳文を読む。端末内のSupertonic 3（設定から約220MBをダウンロード）か、Androidの読み上げエンジンを選べる |

翻訳モデルは0.8B（既定、約570MB）と2B（設定で選んだときだけダウンロード、約1.8GB）を切り替えられます。翻訳はSnapdragonの端末ではGPU（OpenCL）、それ以外の端末ではCPUで動きます。

個人の趣味で作っているアプリです。動作を確かめた端末は限られており、無保証です。

## インストール

1. [Releases](https://github.com/kagerouttepaso/PlamoTranslate/releases) から `PlamoTranslate-<版>.apk` を端末にダウンロードする。
2. ファイルを開き、「提供元不明のアプリのインストール」を、開いたアプリに許可する。
3. インストールしてアプリを開き、最初に出る「モデルの準備」の画面で「ダウンロード」を押す（約836MB。Wi-Fiで）。
4. 画面翻訳は「他のアプリの上に重ねて表示」と画面共有、会話翻訳はマイク、カメラ翻訳はカメラの許可を、使うときに求められる。
5. 画面翻訳の訳の下から元の文字が透けるのが気になる場合は、設定の画面で「訳の枠を透かさない」をオンにし、画面の手順に沿ってユーザー補助の「PLaMo翻訳（画面翻訳の訳の枠）」を有効にする（任意）。Android 13以降は、先にアプリ情報の︙から「制限付き設定を許可」が要る。画面の文字や内容は読み取らない。

新しい版が出たら、設定の画面の「このアプリについて」で「更新を確認」→「ダウンロードして更新」を押すと、Releasesから取って上書きできます（設定とモデルは残ります）。初回だけ「提供元不明のアプリのインストール」の許可を求められます。

動く端末の条件：Android 13以上、64bit（arm64）。メモリは6GB以上を目安にしてください。翻訳が遅い端末では、設定の画面の「パフォーマンス」でスレッド数などを変え、「速さを測る」で比べられます。

## ビルド

Windows・JDK 17・Android SDK（API 36）・NDK r28以降で作っています。手順は [docs/06_開発環境.md](docs/06_開発環境.md)。

```powershell
git clone --recurse-submodules https://github.com/kagerouttepaso/PlamoTranslate.git
cd PlamoTranslate
.\tools\get-sherpa-onnx.ps1
$env:PYTHONUTF8="1"
.\gradlew.bat :app:assembleDebug
```
