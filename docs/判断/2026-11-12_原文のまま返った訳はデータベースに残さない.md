# 原文のまま返った訳はデータベースに残さない

- 状態：有効
- 問題：データベースに書く訳を点検していなかったので、2Bが「Sounds good」を訳さずに返した訳が2Bの訳として控えられ、0.8Bでも原文のまま出続けた。
- 決めたこと：訳が原文のままなら、データベースには書かない（メモリには残す）。
- 理由：長く残る控えに失敗した訳が入ると、モデルを替えても直らない。
- 再発を防ぐもの：長く残す控えには、空でなく原文の写しでもない訳だけを書く（`docs/設計/翻訳コア.md`「控え」、単体テスト `TranslationStreamTest` の「長く残す控えを引き_写しは残さない」）。
