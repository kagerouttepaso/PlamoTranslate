# 会話翻訳は準備が済むと聞き始める

- 状態：有効
- 問題：Android の会話翻訳では、音声認識と翻訳モデルの読み込みが終わるのを待ち、利用者が開始を押す必要があった。
- 決めたこと：会話画面を開いたときだけ、準備とマイクの許可がそろうと自動で聞き始める。停止後と権限を断った後は、利用者の開始操作を待つ。
- 理由：画面を開く操作で聞き取りを始める意思を示せる。モデルの準備完了と停止を同じ状態遷移で扱えば、読み込み直しや遅れて届いた権限応答でマイクが再び入るのを防げる。
- 再発を防ぐもの：`ConversationSessionTest` で、準備完了の重複、停止後の再開、準備中と権限待ちの停止・終了、開始と終了の回数を確かめる。
