# 無料のアプリでのPLaMoの利用は非商用の範囲とみる

- 状態：有効
- 問題：PLaMoの重みを使うアプリを無料で配るとき、ライセンス上の扱いを決める必要があった。
- 決めたこと：アプリを無料で配る使い方は、PLaMoの「個人利用と非商用利用は事前登録なしで無料」の範囲とみる。重みはアプリに同梱しない。
- 理由：モデルのページの記載（2026-11-06に確認）。ほかのモデルは、PP-OCRv6 mangaがApache-2.0、Silero VADがMIT。SenseVoiceのモデルライセンス（FunASR）の本文は確かめていない。商用で使うなら、PLaMoの商用の条件とあわせて確かめる。
- 再発を防ぐもの：なし（選択）。表示の判断は [PLaMoのライセンスの表示を入れ重みは同梱しない](2026-11-08_PLaMoのライセンスの表示を入れ重みは同梱しない.md)。
