# Languageを独立したファイルへ分け共通のモジュールは作らない

- 状態：置き換え（→ [端末に依存しない部品をcore-pipelineに置く](2026-11-12_端末に依存しない部品をcore-pipelineに置く.md)）
- 問題：言語の型 `Language` を、`core-*` の各モジュールが同じ型で受けるかを決める必要があった。
- 決めたこと：`Language` を `core-llm` の `Language.kt` へ分け、`isChinese`・`sameAs` も `Language` の側へ移す。言語のコードの変換（`zh-hans` など）は各モジュールに残す。
- 理由：`core-*` が同じ型で受けるには、共通のモジュールへの依存を足すことになり、「`core-*` どうしは依存しない」決まりを崩す。
- 捨てた案：共通の小さなモジュールを作り、各部品の境界で同じ型を使う。
- 再発を防ぐもの：なし（選択）
