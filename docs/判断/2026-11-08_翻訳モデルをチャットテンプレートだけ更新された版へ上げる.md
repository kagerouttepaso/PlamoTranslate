# 翻訳モデルをチャットテンプレートだけ更新された版へ上げる

- 状態：有効
- 問題：配布元が翻訳モデルのチャットテンプレートを更新し、初版の0.8B（`03891e90`）はもう取れなかった（403）。
- 決めたこと：翻訳モデルを最新のコミット（0.8B `e10c327b`、2B `d44589ec`）に固定する。SenseVoiceは `2365baea`、漫画用OCRは `de0e793d`。
- 理由：更新はGGUFの付属情報のチャットテンプレートだけで、旧版とファイルの末尾4MB（重みの部分）のハッシュが一致した。アプリはチャットテンプレートを使わず、PFML3のプロンプトを自分で組み立てているので、訳は変わらない。
- 再発を防ぐもの：なし（選択）
