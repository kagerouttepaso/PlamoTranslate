# 認識器を行ごとに選びまとまりは位置で組み直す

- 状態：有効
- 問題：複数の認識器の結果を段落ごとに選んでいたので、日本語の解説に韓国語の引用が混ざった段落で、片方の言語が崩れた。
- 決めたこと：複数の認識器の結果から、段落ごとではなく行ごとに1つを選び、選んだ行を位置関係でまとまりに束ねる（`BlockMerger`・`LineClusterer`）。
- 理由：行ごとにすると、漫画2ページの一まとまり率が35%から100%になった。
- 捨てた案：段落（ML Kitのブロック）ごとに認識器を選ぶ。
- 再発を防ぐもの：`CLAUDE.md`「画面翻訳を変えたら評価を回す」。`docs/設計/画面翻訳.md`「行の選び方とまとめ方」。
