# カードの文字を大きくし話した人ごとの色と話し中の枠を付ける

- 状態：有効
- 問題：話し中のカードは動いていることを見せるだけの表示で、2人で注視して読むのに向かなかった。原文が小さく、自分の言葉がどう認識されたか分からず、相手側のカードの色が背景と混ざった（作者の指摘）。
- 決めたこと：原文20sp・訳26spにし、「誰が何語から何語へ」の見出しと話した人ごとの色を付け、話し中のカードを枠で囲んで確定したカードと同じ大きさで出す。地の色は両面で同じにする。
- 理由：話し中のカードも2人で読むものとして扱う。原文が読めないと、認識の誤りに気づけない。
- 再発を防ぐもの：`docs/設計/会話翻訳.md`「画面」
