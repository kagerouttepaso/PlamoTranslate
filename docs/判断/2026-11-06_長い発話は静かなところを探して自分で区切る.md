# 長い発話は静かなところを探して自分で区切る

- 状態：有効
- 問題：長い発話をVADの最長（15秒）で区切っていたので、区切った後に次の話し始めを検出し直す間の音声が抜け、次のカードの話し始めが欠けた（作者の指摘）。
- 決めたこと：VADの最長を600秒にして区切らせず、14秒たまったら直近4秒の一番静かな0.1秒で区切る。認識する音声はVADの切り出しでなく、自分でためた `SpeechBuffer` から取る。
- 理由：自分でためた音声から切り出せば、区切りの前後で音声が抜けない。
- 捨てた案：VADの最長で区切る。
