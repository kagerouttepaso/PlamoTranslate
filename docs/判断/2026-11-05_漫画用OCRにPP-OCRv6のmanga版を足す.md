# 漫画用OCRにPP-OCRv6のmanga版を足す

- 状態：有効
- 問題：ML Kitは縦書きの中国語の字を読み落とした。
- 決めたこと：作者の決定で、PP-OCRv6 manga（検出1.7MB＋認識20.2MB、Apache-2.0、日本語・中国語用）を足す。漫画用OCRの確信度のしきい値は0.8。
- 理由：PCで `tools/ocr-spike.py` により、中国語版3ページ・吹き出し31個の文字の正解率を比べた（下表）。確信度は、PCで中国語の行が中央値0.99、韓国語の行は90%点でも0.75だった。
- 捨てた案：PP-OCRv5 mobile（検出4.6MB＋認識15.8MB）。
- 再発を防ぐもの：なし（選択）

| ページ | ML Kit | PP-OCRv6 manga | PP-OCRv5 mobile |
| --- | ---: | ---: | ---: |
| 4/30（吹き出し13） | 75.7% | 97.4% | 94.1% |
| 7/30（吹き出し10） | 42.9% | 84.5% | 61.9% |
| 8/30（吹き出し8） | 16.2% | 93.2% | 91.9% |
