# 書き起こしの試走結果と認識器を再利用する

- 状態：有効
- 問題：Qwen3-ASR の実行先を指定すると、会話翻訳を開くたびに試走を繰り返していた。計測した認識器はすべて閉じていたため、採用した候補のモデルをもう一度読み込んでいた。
- 決めたこと：GPU 指定では既知音声を1回照合する。CPU 指定では同じ条件で保存したスレッド数の選択を使う。候補を比較するときは暫定首位の認識器を保持し、比較に勝った認識器を書き起こしに渡す。
- 理由：変更前の REDMAGIC 11 Pro のログでは、準備に GPU 指定で約10秒、CPU 指定で約33秒かかり、保存済みの自動選択では約2.7秒だった。GPU モデルの読み込みは1回約3.5秒を占めた。比較中は一時的に認識器2つ分のメモリを使うが、採用後の読み込みを省ける。
- 再発を防ぐもの：`TranscriptionTunerTest` は設定ごとの読み込みと試走の回数、採用した認識器の引き渡し、取り消し・例外時の解放を確かめる。
