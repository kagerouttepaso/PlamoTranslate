# 区切る位置は言語の継ぎ目で探す

- 状態：有効
- 問題：話している最中の交代で、区切る位置を静かさだけで探していたので、継ぎ目に間が無いとき、新しい言語の文の中の小さな間（「조금만」と「생각」の間など）を選び、新しい言語の最初の語が前のカードに入って消えた。
- 決めたこと：話している最中の交代では、0.25秒ずつずらしながら1秒ずつ言語を判定して継ぎ目を探し、その前後の一番静かな0.1秒で区切る。
- 理由：継ぎ目の前後で探せば、新しい言語の語を前のカードに入れない。
- 捨てた案：静かさだけで区切る位置を探す。
