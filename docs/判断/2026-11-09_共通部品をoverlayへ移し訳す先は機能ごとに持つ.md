# 共通部品をoverlayへ移し訳す先は機能ごとに持つ

- 状態：一部置き換え（→ [翻訳の契約をTranslationStreamの1本にしコアを付け替える](2026-11-12_翻訳の契約をTranslationStreamの1本にしコアを付け替える.md)。`overlay/` のまとめ訳し `BatchTranslator` が無くなった）
- 問題：画面翻訳とカメラ翻訳の共通部品が画面翻訳の `screen` にあり、カメラ翻訳が画面翻訳の持ち物を使っていた。訳す対象を選ぶとき（`selectTargets`）も、画面翻訳の訳す先（日本語）で訳す必要を決めていた。そのため、カメラ翻訳で訳す先を英語・韓国語などにしても日本語の行を訳さず、訳す先が韓国語でもハングルの行を韓国語へ訳していた（コードの整理の途中で見つけた）。
- 決めたこと：共通部品を `overlay/` へ移す。訳す先は各機能が持ち（画面翻訳は `SCREEN_TARGET`、カメラ翻訳は選んだ言語）、`selectTargets` の訳す先を必須の引数にする。
- 理由：訳す先を必須の引数にすると、機能ごとの値を渡さない呼び出しはビルドが通らない。
- 再発を防ぐもの：単体テスト `TranslationTargetsTest`（訳す先ごとに訳さない文字種が変わる）。`docs/設計/画面翻訳.md`「訳す対象と翻訳」。
