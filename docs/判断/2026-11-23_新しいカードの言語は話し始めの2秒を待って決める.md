# 新しいカードの言語は話し始めの2秒を待って決める

- 状態：有効
- 問題：新しいカードの最初の途中訳が、話し始めから Qwen3-ASR で約4.1秒、SenseVoice で約3.1秒（Windows、[文末の無音では途中の書き起こしを頼まない](2026-11-23_文末の無音では途中の書き起こしを頼まない.md)の測定）かかる。途中の書き起こしはカードの言語が要り、カードの言語は話し始めから `SegmentationProfile.cardLanguageSeconds`（既定2秒）たまってから決める。最初の言語判定を頼むまでが中央値2.27秒で、待ちの大半を占める。
- 決めたこと：2秒の待ちは、カードの言語を誤らないための代償として残す。待ちを省く仕組みは足さない。
- 理由：言語を指定した書き起こしは、カードの言語を決め直す根拠に数えない（[会話のカードの言語を書き起こしの言語と利用者の指定でも決める](2026-11-19_会話のカードの言語を書き起こしの言語と利用者の指定でも決める.md)）。誤った言語で書き起こすと、そのカードは後から戻らない。短い音声の判定は誤りやすく、2秒の英語「OK.」を韓国語0.55と判定した例がある（`docs/バックログ.md` の相手の自動判定の項目）。待ちが効くのはカードの最初だけで、言語が決まった後の途中結果は待たない。
- 捨てた案：
  - 前の話し手の言語を仮に使って途中の書き起こしを始める：2秒以内に文が終わると、仮の言語で文を書き起こし、上の理由で戻らない。対話では3秒の無音で区切った後に話すのは相手であることが多く、前の話し手の言語は外れやすい。
  - SenseVoice の言語判定で捨てている書き起こしを最初の原文に出す：早く出せるのは原文だけで、訳は言語が決まるまで出せない。言語を誤った原文が出て差し替わることがあり、SenseVoice だけの経路が増える。Qwen3-ASR では識別を Whisper tiny が行うので使えない。
- 再発を防ぐもの：なし（選択）。待ちの長さは詳細設定の「音声認識の調整」で変えられ、長さごとの言語の正解率は `docs/バックログ.md` の未確認の項目にある。
