# 評価の描画を実機の枠に合わせる

- 状態：有効
- 問題：評価の描画（`BenchActivity.render`）が、枠の広げ方・内側の余白・文字の大きさの範囲を実機と別の値で持っていた。評価は枠を8×4px広げ、実機は4dp×2dp（この端末で約12×6px）広げて横書きの内側に2dpの余白を取っていた。
- 決めたこと：評価の描画の値を、実機と同じ値（`OverlayStyle`）にする。
- 理由：合わせると、9sp未満の訳の数が画像ごとに±1動いた。認識したまとまり・訳す対象・訳文は、整理の前後で漫画・一般画面14枚と英語の漫画4枚（自動）とも全件一致した。それより前の「欠け」の数は、枠の大きさが実機とずれた状態で測っている。
- 再発を防ぐもの：枠の広げ方・文字の大きさの範囲・縁取りを `OverlayStyle` の1か所にまとめ、評価も同じ値を使う（`docs/設計/画面翻訳.md`「訳文の重ね表示」）。
