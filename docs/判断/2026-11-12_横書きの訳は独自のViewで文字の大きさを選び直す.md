# 横書きの訳は独自のViewで文字の大きさを選び直す

- 状態：有効
- 問題：`TextView` の自動縮小は、大きさの決まった窓では `append()` で文字が増えても計算し直さず、最初の短い訳で決めた大きさのままはみ出していた。作者の指摘「2行分の高さがないのに2行になって見切れる」「長文を訳している間、大きい文字で見切れたままがしばらく続く」。
- 決めたこと：横書きの訳を `HorizontalTextView`（`Yokogaki`）で描き、訳が増えるたびと枠の大きさが変わるたびに、枠に収まる最大の大きさ（7〜22sp）を二分探索で選び直す。
- 理由：訳が流れて増えるたびに選び直せば、途中でも枠に収まる。
- 捨てた案：`TextView` の自動縮小。
- 再発を防ぐもの：`docs/設計/画面翻訳.md`「訳文の重ね表示」
