# 会話の言語に中国語を足し広東語は繁体字として訳す

- 状態：有効
- 問題：作者が会話の言語に中国語を足し、自分の言語も選びたいと望んだ。会話で使える言語はSenseVoiceが聞き分けられる言語で決まり、広東語はPLaMoに無い。
- 決めたこと：相手に中国語（簡体字）と中国語（繁体字・広東語）を足し、自分の言語も日本語・韓国語・英語・中国語から選べるようにして保存する。広東語は繁体字の書き言葉の中国語として訳す。相手の選択は5つになったのでチップからメニューにする。
- 理由：SenseVoiceは広東語を聞き分けるが、PLaMoは広東語を訳せないので、近い書き言葉として訳す。
- 再発を防ぐもの：なし（選択）
