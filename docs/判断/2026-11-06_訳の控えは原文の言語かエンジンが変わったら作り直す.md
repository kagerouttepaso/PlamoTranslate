# 訳の控えは原文の言語かエンジンが変わったら作り直す

- 状態：置き換え（→ [翻訳の契約をTranslationStreamの1本にしコアを付け替える](2026-11-12_翻訳の契約をTranslationStreamの1本にしコアを付け替える.md)）
- 問題：まとめ訳し（`BatchTranslator`）の控えがエンジンを見ずに使い回され、閉じたエンジンで訳し続けて失敗した。
- 決めたこと：まとめ訳しの控えを、原文の言語かエンジンが変わったら作り直す（`reuseOrCreate`）。
- 理由：控えが持つエンジンを今のエンジンと照らせば、閉じたエンジンを使わない。
- 再発を防ぐもの：置き換え先の、流れが訳し始めるたびに今のエンジンを受け取る形。
