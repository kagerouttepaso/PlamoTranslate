# llama.cppを自前でビルドしPFML3を直接組み立てる

- 状態：有効
- 問題：plamo3アーキテクチャは2026-11-05公開で、既存のKotlinのラッパーライブラリは同梱のllama.cppが古く、plamo3を読めない。
- 決めたこと：llama.cppをgit submoduleで取り込み、Gradleの `externalNativeBuild`（CMake）で一緒にビルドして、自前の薄いJNIで包む。plamo3に対応した版を固定する。プロンプトはチャットテンプレートを使わず、PFML3を直接組み立てる。
- 理由：モデル公式の説明も、アプリへの組み込みではPFML3を直接組み立てる方法を勧めている。JNIとGradleの構成はllama.cppの `examples/llama.android` を参考にした。
- 捨てた案：既存のKotlinのラッパーライブラリ。
- 再発を防ぐもの：なし（選択）。版の固定は `CLAUDE.md`「外部ライブラリの版を固定する」。
