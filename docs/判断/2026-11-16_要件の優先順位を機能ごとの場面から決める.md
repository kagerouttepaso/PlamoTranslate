# 要件の優先順位を機能ごとの場面から決める

- 状態：有効
- 問題：要件どうしがぶつかったとき（速さと正確さ、表示の安定と読み取りの正確さなど）にどちらを取るかが要件に無く、変更のたびに判断が揺れた。同じ語彙を持つブラウザー拡張版の並びを写す案も出たが、使う場面も、解決を求められる問題も違う
- 決めたこと：
  - どの機能でも最上位は「外へ出さない」。その次からの並びは、機能ごとの場面といちばん困る失敗から決め、`docs/要件.md`「機能ごとの優先順位」に置く
  - 会話翻訳：話し手と言語を取り違えない＞会話を途切れさせない＞読める区切り＞確定訳の速さ
  - 画面翻訳：下のアプリの操作を妨げない＞古い訳・別の場所の訳を出さない＞原文の位置と範囲に収める＞読みやすい訳語＞速さ
  - カメラ翻訳：読み違えた原文を訳さない＞表示の安定＞速さ＞電池
  - テキスト翻訳：誤訳しない＞読みやすい訳語＞速さ
  - 音声認識モデルの既定は決めない。利用者が初回の「モデルの準備」で選ぶ。画面翻訳の速さの目標は変えない
  - あわせて、要件から日付・経緯を外し、今の作りと食い違う項目（画面翻訳の撮るきっかけ、タップでの原文との切り替え、会話翻訳の言語）を直した
- 理由：作者の決定。カメラ翻訳は、表示が安定していても、正しい文が出ることのほうが大事（食材や薬のラベルでは実害につながる）。会話翻訳は、0.11.0で作者が決めたこと（相手の言語が確かになるまで訳す向きを決めずに待つ、交代の確定は1〜2秒遅れてよい）から導いた
- 捨てた案：ブラウザー拡張版の1つの並び（外へ出さない＞誤訳しない＞レイアウトを崩さない＞読みやすい訳語＞速さ）を全機能にそろえる（場面が違い、会話の取り違え・画面翻訳の操作の妨げのような、この機能に固有の失敗を表せない）
- 再発を防ぐもの：`docs/要件.md`「機能ごとの優先順位」。下の項目のために上の項目を損なう変更は作者の判断なしに入れない
