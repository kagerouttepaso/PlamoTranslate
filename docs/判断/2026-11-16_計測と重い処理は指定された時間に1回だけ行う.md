# 計測と重い処理は指定された時間に1回だけ行う

- 状態：有効
- 問題：開発に使うPCは、ほかの作業にも使われている。AIが作業の途中で性能の計測や全モジュールのビルドを回すと、そのPCでのほかの作業を妨げ、変更が固まる前の数値で判断することにもなる
- 決めたこと：性能の計測（実機の速さ、`tools/run-bench.ps1` の評価など）、全モジュールのビルド、長い試験は、変更を固めてから作者が指定した時間に1回だけ行う。それまでは「未計測」と報告し、何をどの手順で測るかを書いておく。触れたモジュールの単体試験と `tools/` の検査は、いつ回してもよい
- 理由：作者の決定。計測を最後に1回にすると、途中の変更で何度も測り直す無駄も減る
- 再発を防ぐもの：`CLAUDE.md`「計測や重い処理は指定された時間に1回だけ行う」
