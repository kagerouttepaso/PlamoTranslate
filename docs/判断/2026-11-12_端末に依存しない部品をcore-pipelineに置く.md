# 端末に依存しない部品をcore-pipelineに置く

- 状態：有効
- 問題：作者の指示「クリーンアーキテクチャのエッセンスで、層ごとに共通と個別を分ける」。層の決まりを文書だけに置くと崩れる。
- 決めたこと：状態遷移・判定器・翻訳の契約・言語の型・PFML3プロンプトの組み立てなど、端末に依存しない部品を、Androidに依存できないKotlin/JVMのモジュール `core-pipeline` に置く。
- 理由：モジュールで分ければ、Androidの型を書くとビルドが通らず、依存の向きをビルドで強制できる。端末なしの単体テストで確かめられる。
- 捨てた案：言語の型だけ `core-llm` に置き、共通のモジュールを作らない（[Languageを独立したファイルへ分け共通のモジュールは作らない](2026-11-09_Languageを独立したファイルへ分け共通のモジュールは作らない.md)）。
- 再発を防ぐもの：`docs/設計/アーキテクチャ.md`「層とモジュール」「設計の原則」、`CLAUDE.md`「設計の幹を守る」。
