# 会話の聞き取り中のカードを音声認識のカードの番号で持つ

- 状態：有効
- 問題：音声認識（`SpeechSegmenter`）はカードに番号を付けて管理していたが、会話の側（`ConversationSession`）へは番号を渡さず、同じカードを別の手がかりで推し量り直していた。話し中かは `Speaking(true/false)` から、区切った書き起こし待ちのカードは押した回数（`CutRequested`）と区切りを終えた出来事（`CutDone`）の数から、途中結果がどのカードのものかは「待ちの列の先頭」とみなして決めていた。`Speaking` はカードの順に出していたので、前のカードを書き起こしている間は届かず、区切るボタンは話していないときも押せた。話していないときに押すと `CutDone` だけが余り、ほかのカードの待ちの表示が先に消えた。止める順番（`Flushed` を待ってから止まる）は `ConversationViewModel` が持ち、試験が無かった。作者の要望は、区切れないときは区切るボタンを押せず「話してください」と出し、話し始めるとその場で「区切る」に変わること。
- 決めたこと：
  - 音声認識の出来事（`SpeechEvent`）の聞き取り中のカードの分を、カードの番号を持つ4つ（`CardOpened`・`CardText`・`CardClosed`・`CardFinished`）にした。開く・閉じる・途中の文字はその場で出し、確定はカードの順に出す。何も聞き取れなかったカードも、発話の無い確定で閉じる。`Speaking`・`CutDone`・番号の無い `Partial` と `Final` は消した。
  - `ConversationSession` は、聞き取り中のカードを番号ごとの1つの列（`listeningCards`）で持つ。話し中のカードと書き起こし待ちの列を分けて持つこと（`live`・`queued`）と、押したときに先回りして並べること（`CutRequested`）はやめた。区切るボタンを押せるか（`canCut`）は、聞いていて話し中のカードがあるかで決め、別の状態は持たない。
  - 始めと止める順番を `ConversationSession` の状態遷移へ移した：始める（`Started`）で `Effect.Begin`、停止（`StopRequested`）で `Effect.Flush`、`Flushed` で `Effect.Finish`、画面を閉じる（`Closed`）と確定を待たずに `Effect.Finish`。`Begin` と `Finish` は1回ずつ対で返し、聞いている間だけ変える翻訳のスレッド数は、この対で変えて戻す（始めと終わりが別々の場所にあると、止めている途中で画面を閉じたときに戻し忘れる）。
  - テキスト翻訳の音声入力は、最初に開いたカードの番号の途中の文字と確定だけを使う（途中の文字はその場で届くので、番号を見ないと区切りより後ろの音声の文字が欄に出る）。
  - 押せないときのボタンの名前は「話して」（各言語で「区切る」と同じくらいの短い語）。丸の中に大きく出すためで、長い語（「話してください」）は丸からはみ出した（作者の指摘）。それでも収まらない言語の語は、文字を小さくして収める。
  - 途中訳はカードの番号で持ち、話し始め・確定ごとの世代番号はやめた。
- 理由：カードの正本は音声認識にある。番号を1本の識別子として会話の側まで通せば、推し量り直す規則（数の対応・列の先頭）が要らなくなり、ずれようがない。新しい種類の情報や状態を足さずに、作者の要望（押せる・押せないの切り替え）が今の状態の購読で出せる（作者の指示：機能を足すのでなく、今の仕組みをまとめ直す）。押したときに先回りして並べるのをやめても、閉じた出来事（`CardClosed`）はセグメンターのスレッドからその場で届き、重い書き起こしを待たない。
- 変わった振る舞い：前のカードを書き起こしている間に話し始めても、その場で話し中のカードが出て、途中の文字も出る（以前は前の確定を待った）。話していないときは区切るボタンを押せない。止めた後に届いた途中の文字は出さない。閉じる前に訳し始めた途中訳は、書き起こし待ちのカードに出す（以前は区切ったら捨てていた）。カードの区切り方（区切る位置と書き起こし）は変えていない。
- 確かめたこと：REDMAGIC 11 Pro で、FLEURS（CC BY 4.0）の日本語と韓国語の文をつないだ見立ての会話を音声ファイルとして流し（SenseVoice、20文ずつ、9本）、変更の前後で確定したカードを `tools/score-conv.py`・`tools/score-speaker.py` で比べた。交代の間が長い6本も、文の前後の無音を落として交代の間を0.3〜1.2秒にし、半分ほどの交代で次の人が前の人の文の終わりに重ねて話し始める3本も、カードの数・正解の切れ目で切った数・話し手の交代の取りこぼしは、実時間で流すことによる揺れ（カード1枚・切れ目1〜2か所）の範囲で同じだった（素早い交代の3本で、交代の取りこぼしは前1回・後2回（どちらも48回中））。区切るボタンは、話していないときに「話して／Speak」で押せないことを端末の画面で見た。
- 捨てた案：今の出来事の上に、話し中かを別に知らせる出来事と「区切れるか」の状態を足す。推し量り直しが残ったまま、同じことを表す状態が増える。
- 再発を防ぐもの：`docs/設計/会話翻訳.md`「エンジンと出来事」「聞き取り中のカード」。試験は `SpeechSegmenterTest`（その場で開く・発話の無い確定・確定の順）と `ConversationSessionTest`（カードごとの置き換え、押せるか、止める順番）。
