# 速さの計測に同時に訳したときの合計の速さを足す

- 状態：有効
- 問題：設定の「速さを測る」は1文の速さしか測らず、測る値が「同時に訳す数」の設定と関係しなかった。作者の指摘「同時に訳す数を変えても、速さを測るの生成の値が24トークン/秒のまま変わらない」。
- 決めたこと：「速さを測る」は1文の速さに加えて、今の「同時に訳す数」での合計の速さ（自動調整と同じ測り方）も出す。
- 理由：合計の値は原文の読み込みを含むので、1文の生成の速さより小さく出る（2Bで1文の生成24、同時に1件の合計22）。
- 再発を防ぐもの：`docs/設計/翻訳コア.md`「速さの確かめ方」「自動で調整」
