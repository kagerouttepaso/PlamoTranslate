# 判定を同じ形にそろえて中核に置く

- 状態：有効
- 問題：作者の問い「判定器は2つだけか」を受けて調べると、観測から判断を出す部品が層ごとに散らばっていた。
- 決めたこと：観測から判断を出す部品（撮った1枚が使えるか・訳す対象・開始・有効性・誰への操作か・場面・訳の点検・同じ原文か）を、「観測と前の状態 → 判断と次の状態」の形にそろえて中核に置く方針にする。この時点で中核にあるのは判定A・Bと `TranslationChecks` だけで、ほかはまだ移していない。
- 理由：中核に置けば、端末なしの単体テストで確かめられ、判定が層ごとに散らない。
- 再発を防ぐもの：`docs/設計/アーキテクチャ.md`「判定の一覧」「設計の原則」
