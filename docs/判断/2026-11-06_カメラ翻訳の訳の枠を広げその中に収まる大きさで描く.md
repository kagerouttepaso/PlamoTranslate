# カメラ翻訳の訳の枠を広げその中に収まる大きさで描く

- 状態：有効
- 問題：日本語の訳は原文より長く、1行の高さの枠では下の行にはみ出した（作者の指摘「四角形が折り重なって読めない」）。広げすぎると大きすぎた（作者の指摘「四角形の範囲が大きすぎる」）。
- 決めたこと：文章のモードでは、訳の枠を右は同じ段落の右端まで（元の幅の半分まで）、下は次の行の手前まで（下に行が無ければ行の高さの半分まで）広げ、7〜26spの中で収まる大きさで描き、はみ出す分は切る。
- 理由：右と下に上限を付ければ、訳が入る広さを取りつつ、ほかの枠に重ならない。
