# 長い発話の確定の待ちは区切り方を変えて縮めない

- 状態：有効
- 問題：0.6秒の間が無いまま14秒話し続けた発話は、長い発話として区切った後に、残り（最長14秒）を初めから書き起こす。REDMAGIC 11 Pro では、このカードは話し終えてから確定まで3〜4秒かかり、要件の目標（発話終了から確定訳の表示まで1.5秒以内）を外れる。
- 決めたこと：区切り方と、話している間の書き起こしの順番は変えない。長いカードの確定の待ちは、今の長さのまま受け入れる。
- 理由：作者の決定。長いカードがたまる会話では、話している間の振る舞いが安定していて、確定の待ちがそろっている方が扱いやすい。縮められるのは長いカード1枚あたり1.5〜2.5秒で、14秒話した後の待ちとしては小さい。REDMAGIC 11 Pro の 0.14.1-beta.3 で、書き起こしは発話1秒あたり256〜313ms だった。
- 捨てた案：話している間に短い息継ぎでも文にして先に書き起こす（話している間の書き起こしが増え、途中の書き起こしの更新が不規則に遅れる）。カードを短く区切る（文の途中で切れるカードが増え、カードの粒度の目標に反する。`docs/判断/2026-11-13_会話翻訳の長い発話は文の終わりで区切り話し終わりの間を3秒にする.md`）。途中の書き起こしの結果を確定に使う（途中の結果は取り消されることがあり、確定の質が書き起こしの順番に左右される）。
- 見直す条件：発話1秒あたりの書き起こしがもっと遅い端末で、長いカードの確定の待ちが会話を止めるほどになったとき。
- 再発を防ぐもの：なし（選択）。
