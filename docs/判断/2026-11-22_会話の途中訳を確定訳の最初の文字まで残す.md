# 会話の途中訳を確定訳の最初の文字まで残す

- 状態：有効
- 問題：発話の確定と訳文の確定は別の時点に起きる。聞き取り中のカードを確定した発話に置き換えるとき、すでに読めていた途中訳まで失われていた。
- 決めたこと：中核の `ConversationSession` が、同じカードから同じ方向の途中訳を引き継ぐ。確定訳の最初の文字か完了結果が届くまで、Android・PC ともに未確定の訳として表示する。
- 理由：発話が確定しただけでは、読める訳は増えない。途中訳を確定訳と別に持てば、生成を待つ間も読めて、失敗したときに途中訳が確定訳として残ることも防げる。
- 再発を防ぐもの：`ConversationTranslationDisplayTest` で、カードを確定してから確定訳が届くまでの表示と、途中訳がない場合、訳す方向が変わった場合、失敗した場合の表示を確認する。
