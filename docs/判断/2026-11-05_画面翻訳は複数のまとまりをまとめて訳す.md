# 画面翻訳は複数のまとまりをまとめて訳す

- 状態：有効
- 問題：1まとまりずつ訳すと、毎回プロンプト処理の固定費がかかり、1画面で20秒を超えた。
- 決めたこと：まとまりを読み順に最大8行・400文字ずつ改行でつないで1回で訳し、訳文を改行で分けて戻す。行数が合わなければ、そのまとまりだけ1つずつ訳し直す。今は翻訳の契約の `SequentialCore` が受け持つ（[翻訳の契約をTranslationStreamの1本にしコアを付け替える](2026-11-12_翻訳の契約をTranslationStreamの1本にしコアを付け替える.md)）。同時に訳すときの形は [同時に訳すときは1片ずつ訳し訳し直さない](2026-11-12_同時に訳すときは1片ずつ訳し訳し直さない.md)。
- 理由：つなげば、プロンプト処理の固定費が1回分で済む。
- 捨てた案：1まとまりずつ訳す。
- 再発を防ぐもの：なし（選択）
