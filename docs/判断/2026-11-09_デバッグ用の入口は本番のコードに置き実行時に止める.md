# デバッグ用の入口は本番のコードに置き実行時に止める

- 状態：有効
- 問題：デバッグ用の入口（`ScreenTranslateService` の `DEBUG_TRANSLATE`・`DEBUG_CONFIG`、会話翻訳のWAVの流し込み）が本番のコードにあり、`src/debug` へ移すかを決める必要があった。
- 決めたこと：本番のコードに置いたまま、実行時に `FLAG_DEBUGGABLE` を見て止める。
- 理由：`src/debug` へ移すには、サービスとActivityに差し込み口を作る必要があり、今の形より複雑になる。
- 捨てた案：評価用の `BenchActivity` と同じく `src/debug` へ移す。
- 再発を防ぐもの：なし（選択）
