# PCのQwen3-ASRをllama.cppのGGUF版に切り替える

- 状態：有効
- 問題：PC の会話翻訳で Qwen3-ASR（sherpa-onnx）を使うと、話し終わりから確定訳まで中央値10秒を超え、会話にならない。
- 決めたこと：PC の Qwen3-ASR を llama.cpp（mtmd）の GGUF Q8_0 版に切り替える。書き起こしの実行先は試走で選ぶ（[Qwen3-ASRをllama.cppで動かす計画](../作業中/Qwen3-ASRをllama.cppで動かす計画.md)）。採否は旧版との比較で決め、旧版にもある欠落は採否の理由にしない。
- 理由：同じ録音・同じ条件で、Vulkan では話し終わりから確定訳までの中央値が日英11.40→2.92秒、日韓10.48→2.82秒に縮んだ。CPU だけでも遅くならず（日韓は17.99→10.03秒）、Vulkan の部品を外した環境でも完走した。原文の誤りは日英の日本語で21.5%→8.8%、ほかは同程度。日英の録音で英語の1文が丸ごと欠けたが、旧版でも同じ文が同じように欠けており、今回の変更で増えた欠落・重複は無い。
- 捨てた案：
  - 欠落が直るまで切り替えを保留する：欠落はカードの区切り方の既存の不具合で、書き起こしの実装とは別に起きる。保留しても欠落は直らず、遅さだけが残る。欠落は `docs/バックログ.md` で再現と原因の調査に回す。
  - 発話の長さやこの録音に合わせた区切りのしきい値を足す：症状に合わせた定数になり、原因を説明できないまま別の録音で崩れる。
- 再発を防ぐもの：採否の比較では、正解の話者区間と文を時系列で照合し、欠落・重複を旧版と新版で別々に数える（枚数と完走だけでは欠落を見落とす）。PC の取り込み中の遅延と、中核の仮想時間の結果を分けて評価する。

## PC の実時間比較

Windows x64、4コア8スレッド、RTX 4060。配布物の JAR と DLL を使用し、日英・日韓の録音（各6発話）を `AudioCapture` 境界から20 msずつ実時間で投入した。物理マイク・WASAPI・描画時間は含まない。マイク相当の自動判定、自分は日本語、相手は英語または韓国語。翻訳は同じ PLaMo 0.8B、4スレッド、同時数1、言語識別は Whisper tiny 2スレッド。各構成各録音1回。GPU 許可では新版の試走が Vulkan を選択し、CPU のみでは Vulkan バックエンド DLL を除いた。

秒、各欄は中央値／最大。確定待ちは区切りから確定原文まで。発話末は正解の話者区間（0.25秒刻み）の末端、確定訳はカードに訳が届いた時刻。分割された文は最後のカードで測り、欠けた文は計算に含めない。

| 実行先 | 録音 | 確定待ち：旧 → 新 | 発話末から確定訳：旧 → 新 | 訳が出た発話：旧 → 新 |
| --- | --- | --- | --- | --- |
| Vulkan 許可 | 日英 | 5.87／13.97 → 0.06／0.39 | 11.40／16.33 → 2.92／3.55 | 5/6 → 5/6 |
| Vulkan 許可 | 日韓 | 7.29／10.06 → 0.20／0.65 | 10.48／13.17 → 2.82／3.82 | 6/6 → 6/6 |
| CPU のみ | 日英 | 4.14／8.61 → 3.30／9.57 | 7.80／14.54 → 7.36／13.41 | 5/6 → 5/6 |
| CPU のみ | 日韓 | 8.72／13.61 → 5.88／9.26 | 17.99／21.74 → 10.03／15.06 | 6/6 → 6/6 |

旧 CPU の日英では日本語の途中に原文にない英語のカードも出た。新版は訳が届いたカードの順序が逆転せず、日韓は6発話とも方向が合った。新版 CPU の日英では長い日本語のカードの確定に9.57秒、翻訳に1.40秒を要した。今回のカード記録だけでは、この9.57秒を ASR の待機と処理に分離できない。

取り込み前の初回準備／同じプロセスで画面を作り直した後の準備は、Vulkan 許可が旧 5.27／4.83秒、新 34.53／2.08秒、CPU のみが旧 4.50／4.70秒、新 22.59／2.01秒。新版は初回だけ候補を比較する。CPU と Vulkan の準備中断後の起動を混同しないため、別の試験プロファイルで GPU 準備中のプロセスを2回終了し、次の起動で書き起こしが CPU に退避して既知音声のならし運転まで完了することも確認した。

## 仮想時間での原文の比較

`ConversationReplayTest` の PC 用識別器でカードを比較した。本文を NFKC 正規化し、言語ラベル別に連結して編集距離を正解の長さで割った。日韓は文字（空白・記号を除く）、英語は単語。欠落も誤りに含む。時間は採点に使わない。

| 録音 | 原文 | 旧 sherpa | 新 GGUF |
| --- | --- | ---: | ---: |
| 日英 | 日本語 CER | 56/260（21.5%） | 23/260（8.8%） |
| 日英 | 英語 WER | 17/49（34.7%） | 17/49（34.7%） |
| 日韓 | 日本語 CER | 25/260（9.6%） | 29/260（11.2%） |
| 日韓 | 韓国語 CER | 40/120（33.3%） | 39/120（32.5%） |

再現には `PLAMO_REPLAY_DESKTOP=1` と `PLAMO_SHERPA_LIB` を指定し、同じ録音・相手言語で `ConversationReplayTest.replay` を実行する。旧版は `MOCKINGWORD_ASR_FIXTURES` を設定せず、新版は開発手順の GGUF と JNI の場所を指定する。
