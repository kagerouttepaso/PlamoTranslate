# アジャイルに進め毎回実機で触れる版で終える

- 状態：有効
- 問題：音声認識・OCR・実行先などの部品に候補が多く、全部を比べてから組み立てるか、先に端から端まで通すかを決める必要があった。
- 決めたこと：1回の区切り（イテレーション）を数時間〜数日にし、終わりに実機へ入れて作者が触れる状態にする。まず一番簡単に動く1つの実装で端から端まで通し、比較や作り込みは使って不満が出た箇所だけ行う。
- 理由：趣味のアプリで、作者の方針。使って気づいたことで次にやることを決める。
- 捨てた案：全部の部品を比較・計測してから組み立てる（最初に検討した計画）。
- 再発を防ぐもの：なし（選択）。規則は `CLAUDE.md`「進め方」にある。
