# アプリ内のCPUのスレッド数を6にする

- 状態：置き換え（→ [CPUの動かし方を設定で切り替えスレッド数を大きいコアの数にする](2026-11-08_CPUの動かし方を設定で切り替えスレッド数を大きいコアの数にする.md)）
- 問題：CPUで動かすときの既定のスレッド数を決める必要があった。CLI単体では8スレッドが最速だった。
- 決めたこと：CPUで動かすときの既定のスレッド数を6にする。
- 理由：REDMAGIC 11 Proのアプリでは画面描画とCPUを取り合い、8スレッドは生成35トークン/秒、6スレッドは64トークン/秒だった（CPU構成、イテレーション1）。
- 再発を防ぐもの：なし（選択）
