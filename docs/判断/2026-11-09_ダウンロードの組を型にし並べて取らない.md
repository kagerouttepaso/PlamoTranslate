# ダウンロードの組を型にし並べて取らない

- 状態：有効
- 問題：初回の組・2B・読み上げのダウンロードについて、取っている組と失敗した組を見分ける必要があった。
- 決めたこと：初回の組・2B・読み上げを `ModelBundle` の型にし、取っている組と失敗した組を型で見分ける。同時に取るのは1組だけ。
- 理由：どの組も1回きりのダウンロードで、並べても回線の速さを分け合うので、全体の時間はほとんど縮まない。組ごとの状態・中止・失敗の扱いを増やす費用に見合わない。
- 捨てた案：組ごとに `StateFlow<DownloadState>` を持って並べて取る。
- 再発を防ぐもの：なし（選択）
