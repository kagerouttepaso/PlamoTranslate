# 触れるまで訳を残す消え方を足す

- 状態：有効
- 問題：トリッカルのように背景のキャラクターが動き続けるゲームで、訳を出した後に判定Bが画面の動きを原文の変化とみなして消していた。通常のモードは規則3（画面が変わった、0.06〜0.22）、動く画面のモードは規則2（原文の周りが変わった）で消える。キャラクターが原文のすぐ横を通る動きは、原文が動いた・消えた動きと格子の上で見分けられない。
- 決めたこと：作者の要望で、メニューに「訳の消え方」を足し、「触れるまで残す」では判定Bの規則2・3を見ない組（`SceneProfile.untilTouched`）を使う。規則1、ユーザー補助の合図、触れたときの扱いは残す。認識モードとは独立に選べる。
- 理由：ゲームでは台詞を送るのも画面を移るのも触れる操作なので、触れたときののぞきと画面の切り替わりで消せば足りる。端末のログでは、背景が動く横画面で2〜3秒ごとに「画面が変わった」で取り消していた（2026-11-13）。消え方を認識モードに混ぜず別の設定にしたので、白縁の文字の読み方と組み合わせを選べる。
- 捨てた案：浮遊ボタンや上部の表示を押すまで一切消さない（台詞を送っても古い訳が残る）。規則2で動いたます目を外す（キャラクターが新しく入ってきた場所は前に動いていないので外せない）。
- 再発を防ぐもの：`docs/設計/画面翻訳.md`「場面の設定」、`JudgesTest` の「触れるまで残す組」の試験。
