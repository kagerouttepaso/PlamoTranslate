# PDFの状態行には表示位置に近い処理中のページを示す

- 状態：有効
- 問題：複数ページを同時に訳すとき、最初の依頼だけから表示用のページを選ぶと、利用者が別の処理中のページに移っても、状態行は元のページを示し続ける。
- 決めたこと：処理中の段落を含むページから、翻訳の依頼順と同じ距離で表示位置に最も近いものを選ぶ。画面に出すときとページ欄で入力を受けるときにだけ、添字と番号を変換する。
- 理由：3ページ目と4ページ目を並列に訳している状態で4ページ目に移ると、ページ欄には4、状態行には3と表示された。ページ欄も状態行も、添字から表示番号への変換は正しかった。
- 捨てた案：常に表示中のページを状態行に出す方法では、そのページに処理中の段落がない場合も翻訳中と伝えてしまう。
- 再発を防ぐもの：`PdfSessionTest` で並列翻訳中のページ移動と依頼の完了、`PdfViewTest` で添字と表示番号の往復を確かめる。
