# カメラ翻訳は4件ずつまとめて訳す

- 状態：置き換え（→ [カメラ翻訳は頼んだ順に同時に訳す](2026-11-12_カメラ翻訳は頼んだ順に同時に訳す.md)）
- 問題：カメラ翻訳で、まとめ訳しに一度に渡す件数を決める必要があった。
- 決めたこと：一覧から4件ずつ取り出して、画面翻訳と同じまとめ訳し（`BatchTranslator`）に渡し、4件とも訳し終わるまで次を取らない。
- 理由：8件だと2Bで10秒ほどかかり、カメラを動かした後に新しく映った文へ切り替わるのが遅い。実機（REDMAGIC、2B・GPU）では、文字認識が1コマ0.1〜0.5秒（細かい成分表示で1.2秒）、短い行の翻訳が1件0.2〜0.7秒・5件で約2.5秒、一時停止から4件の訳がそろうまで約8秒だった。
- 捨てた案：8件ずつ訳す。
- 再発を防ぐもの：なし（選択）
