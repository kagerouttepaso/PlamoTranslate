# 対面のカードは読む人の言語に面を譲り真ん中に区切るボタンを置く

- 状態：有効
- 問題：会話翻訳の録音で、言語の誤判定による自動の区切りが多すぎた（ぶつ切り）。自動の区切りを厳しくすると、本当に話し手が代わったときに区切り損ねる。作者は、人が明確に区切れるボタンを置き、自動の区切りは粘らせる（1枚にまとまる方へ寄せる）ことを提案し、ボタンを操作欄の真ん中に丸く置くことを求めた。ボタンで操作欄が高くなる分、対面のカードは、その面を読む人の言語の文が面を占めるようにしたい（作者の要望。見出しの「自分・日本語 → 韓国語」は自明、相手向けの面のもう一方の言語は小さくてよい）。1画面は、2人が同じカードの全部を読むので今のままがよい（作者）。
- 決めたこと：操作欄の真ん中に丸い「区切る」ボタンを置き、押すと今話している分を確定して次のカードにする（聞くのは続ける。`SpeechEngine.cut`）。マイクの音量は、横長のバーをやめてボタンの周りの輪にした。対面のカードは、見出しとかかった時間を出さず、読む人の言語の文を26sp、もう一方を14spにし、余白を詰める。読み上げ中だけ🔊を出す。1画面のカードは変えない。
- 理由：区切るボタンは、自動の区切りの取りこぼしを人が補う逃げ道になり、自動の区切りを厳しくしやすくする。両手がふさがる場面もあるので、自動の区切りは残す。対面では、読む人に読めないもう一方の言語は、話した人が聞き取りを確かめる程度に読めればよく、誰が何語で話したかは色と左右と読む人の言語で分かる。
- 捨てた案：区切るボタンを2人の面にそれぞれ置く（操作欄が2段に増え、カードの面がさらに減る。真ん中の1つなら両方から押せる）。
