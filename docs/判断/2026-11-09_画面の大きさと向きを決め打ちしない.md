# 画面の大きさと向きを決め打ちしない

- 状態：有効
- 問題：撮影の仮想ディスプレイ・訳の枠・浮遊ボタン・状態バーの高さを、始めたときの大きさや固定値で持っていた。縦持ちで始めて横画面にすると、横長の画面が縦長の枠に約0.45倍で映り、訳の枠が違う場所に出た（作者の指摘）。状態バーをシステムの縦持ちの既定値で固定していたので、全画面のアプリで一番上の文字を訳さなかった。
- 決めたこと：撮影の仮想ディスプレイ・訳の枠・浮遊ボタン・状態バーの高さを、今の画面から求める。回したら `VirtualDisplay.resize` で大きさだけ変え、受け取り口の `ImageReader` を差し替える。
- 理由：作者の指示「人に配るようになったので、画面サイズなども固定値はやめる」。
- 捨てた案：仮想ディスプレイを作り直す（Android 14以降は1つの許可で1回しか作れない）。
- 再発を防ぐもの：撮る前に今の画面の大きさと比べる（`docs/設計/画面翻訳.md`「画面の撮影」）。状態バーの高さは撮るたびに求める（同「訳す対象と翻訳」）。
