# ユーザー補助が切り離されたら知らせる

- 状態：有効
- 問題：REDMAGICのゲーム支援がユーザー補助を黙って切り離し、透けない訳の枠と合図が失われる。利用者がオフ・オンし直すまで戻らない。
- 決めたこと：設定の「訳の枠を透かさない」がオンで、ユーザー補助が有効なのにつながっていなければ、画面翻訳を始めて3秒後と、つながりが切れたときに、上部の表示とトーストで「オフにしてからオンにする」よう知らせる。設定の画面にも出す。
- 理由：`am crash` で同じ状態を作り、開始時と設定の画面の両方に知らせが出ることを確かめた。
- 再発を防ぐもの：`docs/資料/端末の能力.md`「設計に効く、思わぬ事実」
