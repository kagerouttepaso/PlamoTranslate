# 一般モードと漫画モードの切り替えを作らない

- 状態：有効
- 問題：当初は、漫画用に comic-text-detector と manga-ocr を使い、一般のアプリ画面と漫画をモードで切り替える案だった。
- 決めたこと：一般のアプリ画面と漫画を同じ処理で扱う。
- 理由：漫画用OCRとML Kitを並べて動かし、行ごとに選べば（[認識器を行ごとに選びまとまりは位置で組み直す](2026-11-05_認識器を行ごとに選びまとまりは位置で組み直す.md)）、両方を1つの処理で読めた。
- 捨てた案：モードの切り替え。漫画用に comic-text-detector と manga-ocr を使う案。
- 再発を防ぐもの：なし（選択）
