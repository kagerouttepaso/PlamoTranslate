# AudioTrackへは約46ミリ秒ずつ書く

- 状態：有効
- 問題：1文の音をまとめて `AudioTrack` に書いていたので、書き終わるまで戻らず、止めても・別のものを読んでも・画面を離れても鳴り続け、次の読み上げと重なった（作者の指摘）。
- 決めたこと：読み上げの音を `AudioTrack` へ2048フレーム（44.1kHzで約46ミリ秒）ずつ書き、区切りごとに止めるかを見る。止めたら書いた分も捨てる。画面を離れたら読み上げを止める。
- 理由：短く区切って書けば、止めたときにすぐ黙る。
- 捨てた案：1文をまとめて書く。
- 再発を防ぐもの：`docs/設計/会話翻訳.md`「読み上げ」
