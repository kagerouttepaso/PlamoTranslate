# アプリの更新をGitHubの最新リリースから取る

- 状態：有効
- 問題：配った端末に新しい版を入れる手段が要った（作者の要望）。アプリは翻訳・認識で通信しないことを約束している。
- 決めたこと：正式版は、設定の画面の「更新を確認」「ダウンロードして更新」で、GitHubの最新リリースのAPKを取り、`digest`（SHA-256）・パッケージ名・`versionCode`・署名の鍵を確かめてから `PackageInstaller` で入れる（`update/AppUpdater.kt`）。Google Playで配る版では、規約によりこの機能を外す。
- 理由：通信はボタンを押したときだけにし、起動時には確かめない。翻訳・認識は通信しない、というアプリの約束を崩さないため。
- 再発を防ぐもの：なし（選択）。仕組みは `docs/手順/開発環境.md`「アプリの更新」。
