# ページ再生成の前に単色をRGBで設定し直す

- 状態：有効
- 問題：原文を削除してページを再生成すると、PDFium は ICC 色空間で指定された灰色の塗りを出力せず、ページ全面の矩形が既定色の黒になった。訳文の文字は書き込まれていたが、黒い地に重なって見えなかった。
- 決めたこと：原文の文字を削除したページでは、残るページ直下のパスと文字の単色を、PDFium が返す RGB 値と不透明度で設定し直す。PDFium の公開 API から色空間や所属ストリームを取れないため、単色の設定を変えた別のストリームも再生成の対象になる。
- 理由：元の色を読み取れていても、PDFium の `WriteColorToStream` は RGB と Gray 以外を出力しない。単色を DeviceRGB で指定し直すと、書き換え直後と保存後の背景・罫線が元の色で描かれ、PDFBox で開いた保存版でも色が一致した。
- 捨てた案：フォームの覆い色や背景の推定を変える案は、黒くなったページではフォームの覆いを置いておらず、背景の推定結果も灰色だったため採らない。
- 再発を防ぐもの：`docs/設計/PDF翻訳.md`「訳文の配置」と、合成 PDF で ICC 色の背景・罫線、訳文の検索、保存版の描画を確かめる `PdfDocumentTest`。
