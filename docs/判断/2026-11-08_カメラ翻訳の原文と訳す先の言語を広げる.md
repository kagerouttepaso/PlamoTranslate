# カメラ翻訳の原文と訳す先の言語を広げる

- 状態：有効
- 問題：作者の要望「ライブラリやローカルモデルで対応できる言語は全て選べるように」と、訳す先を選べるようにする要望。
- 決めたこと：原文には、同梱のML Kitの認識器が読める言語（韓国語、中国語の簡体字・繁体字、ラテン文字の25言語）を選べるようにする。セルビア語は入れない。訳す先は53言語から選べるようにする。
- 理由：翻訳は53言語を訳せるので、選べる原文は文字認識で決まる。セルビア語は看板がキリル文字のことが多い。
- 捨てた案：ML Kitのデーヴァナーガリーの認識器を足す（ヒンディー語などが読めるが、APKが大きくなる）。
- 再発を防ぐもの：なし（選択）
