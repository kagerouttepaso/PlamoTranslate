# 雑音の聞き違いを何も話していないものとして扱う

- 状態：有効
- 問題：句読点だけ・あいづちだけ（「.」「Yeah.」「I.」など）の認識結果が、それだけでカードになり、英語と判定されて日本語の文の間に挟まると、話し手の交代とみなされてカードが切れた。作者の指摘「一番大事」。
- 決めたこと：句読点だけ・あいづちだけの認識結果を空にし、カードにも言語の判定にも使わない。「Yes」「OK」「No」は残す。
- 理由：英語で「Yeah」とだけ言ったカードも消えるが、会話の中身を運ばないので、誤って切られる害を重く見た。
- 再発を防ぐもの：単体テスト `AsrTest`（「中身のない聞き違いは空にする」「本当の返事と文は残す」）。
