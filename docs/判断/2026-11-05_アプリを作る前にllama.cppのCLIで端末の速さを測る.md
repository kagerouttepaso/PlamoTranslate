# アプリを作る前にllama.cppのCLIで端末の速さを測る

- 状態：有効
- 問題：アプリを作る前に、端末で翻訳がどれくらいの速さで動くかを知る必要があった。
- 決めたこと：最初の段階（イテレーション0）で、llama.cppのCLI（`llama-completion`・`llama-bench`）を端末の `/data/local/tmp/plamo/` で直接動かし、翻訳と速度を測る（`tools/device-translate.ps1`）。手順はllama.cppのリポジトリにあるAndroid向けの説明の最新版を優先した。CLIの計測は、アプリ内の速さと端末の素の速さを比べる手段として残す。
- 理由：CLIならアプリの作りに関係なく端末の素の速さが分かる。CLI単体では8スレッドが最速だった。15T Proでアプリ内の生成が遅かったときの切り分けにも使った（[CPUの動かし方を設定で切り替えスレッド数を大きいコアの数にする](2026-11-08_CPUの動かし方を設定で切り替えスレッド数を大きいコアの数にする.md)）。
- 再発を防ぐもの：なし（選択）。手順は `docs/手順/開発環境.md`「端末でCLIを動かして測る」。
