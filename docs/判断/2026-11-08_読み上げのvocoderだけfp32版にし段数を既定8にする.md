# 読み上げのvocoderだけfp32版にし段数を既定8にする

- 状態：有効
- 問題：Supertonic 3を段数5で聞くと、話している最中にザラつきがあった（作者の指摘。音割れは無い）。
- 決めたこと：sherpa-onnx向けのint8版のうち、vocoderだけ公式のfp32版（`Supertone/supertonic-3` の `onnx/vocoder.onnx`）に替える（合計約220MB）。段数は3〜16のスライダーにし、既定は8（例文の最初の音まで約1.1秒）。スレッド数は設定に出さない。
- 理由：話している区間の1〜8kHzのスペクトルの平坦さ（日本語10秒の文）と作る時間は下表。ザラつきの主な原因はint8のvocoderで、int8のままでは段数16でもfp32のvocoderの段数5に届かない。vocoderだけfp32にすると改善の大半が得られ、遅くなるのは1〜2割。int8版のonnxは公式版をそのまま量子化したもの（量子化していない2つはハッシュが一致）なので、差し替えて動く。
- 捨てた案：`vector_estimator` もfp32にする（約178MB増え、2〜3割遅くなるわりに差が小さい）。
- 再発を防ぐもの：なし（選択）
