# カメラ翻訳に表とメニューのモードを足す

- 状態：有効
- 問題：表を段落にまとめると、隣のセルや下の行がつながって訳の質が下がった（作者の指摘）。エアコンのリモコンで、「바람／세기」を1語ずつ訳すと「세기」が「世紀」、2語なら「風の強さ」。枠を広げると隣のボタンを覆った。
- 決めたこと：表・メニューのモードでは1行（1セル）ずつ訳し、ボタンの2段書き（行間が行の高さの0.3倍以内で中央のそろった上下2行）だけまとめる。訳の枠は広げない。翻訳に「家電や機器のボタン・表示画面、メニュー、看板、表などに書かれた短い表記。」という背景を渡す。
- 理由：背景の効果（`tools/translate-labels.tsv`・`translate-labels-batch.tsv`、2B）：きれいな文字なら背景なしでも「정지→停止」「일월화수목금토→日月火水木金土」と訳せ、改行でつないでも同じ。背景が効いたのは「송풍」（宋風→送風）だけで、「세기」単独は背景があっても「世紀」。カメラで出た「正地」「花」は、文字認識の読み違いか1文字の切り離しが原因とみている。
- 再発を防ぐもの：なし（選択）
