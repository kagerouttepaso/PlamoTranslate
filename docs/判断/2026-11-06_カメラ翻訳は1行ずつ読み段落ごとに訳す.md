# カメラ翻訳は1行ずつ読み段落ごとに訳す

- 状態：有効
- 問題：カメラの映像はコマごとに読み揺れがある。大きなまとまりのまま読んでいたので、成分表示は数百文字のまとまりに、ラベルの表面は1つのまとまりになり、コマごとの読み揺れで同じ文としてそろわず、訳が出なかった。
- 決めたこと：1行ずつ読み、コマをまたいで同じ行を追って多数決で原文を決め、重なる行を段落にまとめて訳す。追い方と使う行の条件は [カメラ翻訳はほぼ同じ読み取りが2回そろった行だけを使う](2026-11-06_カメラ翻訳はほぼ同じ読み取りが2回そろった行だけを使う.md)。
- 理由：行の単位なら、コマどうしで読み取りを照らし合わせられる。作者の提案「重なる枠は1段落として統合した方が欠落が無くなる」。
- 捨てた案：大きなまとまり（ML Kitのブロック）のまま読んで訳す。
- 再発を防ぐもの：`docs/設計/カメラ翻訳.md`「追跡と多数決」「段落にまとめる」
