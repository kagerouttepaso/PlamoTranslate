# 訳の枠は触れた操作を奥のアプリへ通す

- 状態：有効
- 問題：訳の枠を1つずつタップで消す作りで、字幕の上をスワイプして奥の投稿をスクロールできなかった（作者の指摘）。Android 12以降は、不透明度が上限を超える重ね表示を通り抜ける操作が捨てられる。
- 決めたこと：訳の枠の窓を `FLAG_NOT_TOUCHABLE` にし、表示のオン・オフは浮遊ボタンで一括にする。窓の不透明度は `InputManager.maximumObscuringOpacityForTouch`（既定0.8）に合わせる。
- 理由：枠が操作を受けなければ、奥のアプリをそのまま操作できる。不透明度を上限に合わせないと、通した操作が捨てられる。
- 捨てた案：訳の枠をタップで半透明にする機能。
- 再発を防ぐもの：`docs/資料/端末の能力.md`「重ね表示と触れた操作」。`docs/設計/画面翻訳.md`「訳文の重ね表示」。
