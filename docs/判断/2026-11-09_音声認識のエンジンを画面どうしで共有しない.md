# 音声認識のエンジンを画面どうしで共有しない

- 状態：有効
- 問題：テキスト翻訳の音声入力が会話翻訳のパッケージに依存していた。同じ音声認識のエンジン（約230MB）を画面どうしで共有するかを決める必要があった。
- 決めたこと：モデルの場所を `ModelCatalog.asrDir` に、`MicRecorder` を `audio/` へ移し、テキスト翻訳から会話翻訳への依存をなくす。エンジンは画面ごとに読み込み、画面を閉じたら手放す。
- 理由：共有で省けるのは、2つの画面を行き来したときの読み込みだけ。その代わり、約230MBを持ち続けるか、いつ手放すかの決まりが要る。翻訳モデルと読み上げのモデル（約220MB）も同じメモリに載る。
- 捨てた案：生存期間を `AsrProvider` にまとめて共有する。
- 再発を防ぐもの：なし（選択）
