# 窓単位の撮影は今は入れない

- 状態：有効
- 問題：判定Bの画像を窓単位の撮影にする案（[ユーザー補助の窓単位の撮影で原文を見る](2026-11-12_ユーザー補助の窓単位の撮影で原文を見る.md)）は、ユーザー補助に窓の一覧と撮影の権限を足し、利用者に有効化をやり直してもらう必要がある。
- 決めたこと：判定Bの画像は画面共有のままにする。
- 理由：作者の確認で、判定Bが訳の枠の外周で、Discord・漫画・動く画面のモードとも取り消せた。使って不満が出た所だけ作り込む方針（`CLAUDE.md`「進め方」）。
- 捨てた案：窓単位の撮影で原文を見る（[ユーザー補助の窓単位の撮影で原文を見る](2026-11-12_ユーザー補助の窓単位の撮影で原文を見る.md)）。
- 再発を防ぐもの：なし（選択）。入れるときの場所は `docs/設計/画面翻訳.md`「将来の機能の差し込み口」。
