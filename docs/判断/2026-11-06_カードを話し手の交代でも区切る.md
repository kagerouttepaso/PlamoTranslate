# カードを話し手の交代でも区切る

- 状態：有効
- 問題：カードの区切りを無音だけで決めていたので、確定の無音を2秒に延ばした後、話し手が2秒以内に代わると2つの言語が1枚にまとまり、片方がほとんど読めなくなった。作者の指摘「高速で話し合うときに致命的」「音声入力の受付は続けたまま、カードを区切って訳す向きを切り替えて」。
- 決めたこと：区切りを「文」（VADの0.6秒の無音）と「カード」の2段にし、次の文の言語が前の文と違えば区切る。話している最中も直近1.5秒の言語を見張り、2回続けて違えば区切る。
- 理由：話し手が代わると言語が変わるので、言語の変化をカードの区切りに使える。
- 捨てた案：話し手に2秒の間を置いてもらう（会話のキャッチボールとして良くない）。
