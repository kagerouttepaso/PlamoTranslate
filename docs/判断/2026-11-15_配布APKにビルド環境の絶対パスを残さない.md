# 配布APKにビルド環境の絶対パスを残さない

- 状態：有効
- 問題：ネイティブライブラリのデバッグ情報に、ビルド環境の絶対パスが含まれる。公開APKに端末固有の情報が混入する。
- 決めたこと：アプリのパッケージ作成でもネイティブビルドと同じNDKを指定し、デバッグ情報を除去する。コンパイル時にも、リポジトリとNDKのパスを環境に依存しない接頭辞へ置き換える。
- 理由：ビルド環境が変わっても同じ処理で公開物を保護でき、診断文字列に含まれるソースパスも一定にできる。個別のユーザー名やパスをコードへ埋め込まない。
- 再発を防ぐもの：`app/build.gradle.kts` のNDK指定と `core-llm/src/main/cpp/CMakeLists.txt` の `-ffile-prefix-map`。公開前に最終APKの展開内容を確認する。
