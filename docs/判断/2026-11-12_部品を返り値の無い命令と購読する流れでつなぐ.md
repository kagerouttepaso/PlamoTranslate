# 部品を返り値の無い命令と購読する流れでつなぐ

- 状態：有効
- 問題：翻訳は頼むと結果が返る形、訳の枠は直接書き換える形、見張りはフラグを読む形と、部品のつなぎ方がばらばらだった。
- 決めたこと：部品どうしを、返り値の無い命令と、結果・状態・出来事を流す購読でつなぐ。
- 理由：作者の決定（データの流れを1本にする）。命令はすぐ戻り、結果は購読で届くので、呼ぶ側は部品ごとの待ち方や取り消し方を持たず、届いた結果を出来事として状態遷移の1か所に渡せる（画面翻訳は `TranslationStream` の `updates` を `SegmentDone` などの出来事にしている）。
- 再発を防ぐもの：`docs/設計/アーキテクチャ.md`「部品のつなぎ方」「設計の原則」、`CLAUDE.md`「設計の幹を守る」。
