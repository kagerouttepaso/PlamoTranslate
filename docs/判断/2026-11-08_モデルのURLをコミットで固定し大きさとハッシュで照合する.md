# モデルのURLをコミットで固定し大きさとハッシュで照合する

- 状態：有効
- 問題：アプリが配布元の `resolve/main/` を指したまま、大きさとハッシュを決め打ちで持っていた。配布元は公開後もファイルを差し替える。pfnetは2026-11-06〜11-08にGGUFのチャットテンプレートを4回更新し、そのたびに大きさとハッシュが変わった。漫画用OCRは置き場所を変え、`main` の旧パスは404になった。15T Proで0.8Bのダウンロードが毎回約580MBで失敗した（受け取った大きさが想定を超えた）。
- 決めたこと：Hugging Faceのファイルを `resolve/main/` ではなくコミットを指定したURLで取り、大きさとSHA-256で照合する。
- 理由：コミットを指せば、取るファイルと持っている大きさ・ハッシュが食い違わない。ただし、配布元が古いコミットのファイルを消すと、固定したURLでも取れなくなる（[翻訳モデルをチャットテンプレートだけ更新された版へ上げる](2026-11-08_翻訳モデルをチャットテンプレートだけ更新された版へ上げる.md)）。
- 捨てた案：自分の置き場（GitHubのリリースなど）にモデルの写しを置く。ライセンスの条件の確認と置き場の管理が要るので、今はしない。
- 再発を防ぐもの：`docs/手順/開発環境.md`「モデルの版を上げる」。単体テスト `ModelDownloadsTest`（「ハッシュが合わなければ使わず途中のファイルも消す」）。
