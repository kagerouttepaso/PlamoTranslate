# 署名したAPKをGitHubのリリースで配る

- 状態：有効
- 問題：人に配るようになり、配る場所と、入れた端末で上書きできる署名の扱いを決める必要があった。
- 決めたこと：ソースをMIT Licenseで公開する。正式版は作者が作った鍵で署名し、GitHubのリリースにAPK（`PlamoTranslate-<versionName>.apk`）を置いて配る。タグは `v<versionName>`。最初に公開した版は0.3.4。
- 理由：同じ鍵で署名した新しい版なら、入れた端末で上書きでき、モデルも残る。鍵とパスワードは公開リポジトリに入れられないので、各PCの `local.properties` からリポジトリの外の `keystore.properties` を指す。
- 再発を防ぐもの：なし（選択）。手順は `docs/手順/開発環境.md`「配布用のAPK」。
