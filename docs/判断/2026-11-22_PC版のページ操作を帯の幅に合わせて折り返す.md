# PC版のページ操作を帯の幅に合わせて折り返す

- 状態：有効
- 問題：PDF のページ操作を1行に固定すると、見出し欄を開いて幅を狭めたとき、行末の表示モードと検索にラベルを描く幅が残らない。
- 決めたこと：テキスト翻訳と PDF のページ操作で帯の部品を共用し、各項目を実際の幅で測って折り返す。倍率を変更する3つの操作は同じ行に保つ。
- 理由：帯に使える幅は、ウィンドウ幅、見出し欄の開閉、表示モードのラベルによって変わる。折り返せば、広いときは1行で使え、狭くても検索をマウスで直接選べる。
- 再発を防ぐもの：`PdfPageBarTest` で実際の帯を2つの幅で描き、検索が広いときは先頭行、狭いときは次の行に、同じ幅で表示されることを確かめる。
