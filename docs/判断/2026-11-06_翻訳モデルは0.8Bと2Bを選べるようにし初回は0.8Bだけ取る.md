# 翻訳モデルは0.8Bと2Bを選べるようにし初回は0.8Bだけ取る

- 状態：有効
- 問題：作者が翻訳の品質と速さの違いを確かめたいと望んだ。2Bは約1.8GBあり、全員の初回のダウンロードに入れると重い。
- 決めたこと：既定は0.8B。2Bは設定の画面から追加でダウンロードする（約1.8GB）。既定をどちらにするかは、会話翻訳で2Bの途中訳が追いつくかで決める（`docs/バックログ.md`）。
- 理由：2Bは0.8Bの約2.5倍遅いが、口語の難しい文54文で意味の取り違えが7件→4件に減った（下表。REDMAGIC 11 Pro、GPU、13文は `tools/translate-bench.tsv` の韓・英・中→日、日→韓・英）。2Bは「제가 살게요（おごります）」「좀 빼 드릴게요（値引き）」「4호선 타시면 돼요」「items on hold」「いくらかかりますか（日→韓）」を正しく訳し、0.8Bは取り違えた。両方とも外したのは韓国語の慣用句・皮肉と個別知識。訳の全文は `tools/bench-results/2026-11-06/`。
- 再発を防ぐもの：なし（選択）

| 13文の合計 | 3.9秒（51トークン/秒） | 10.0秒（19トークン/秒） |
