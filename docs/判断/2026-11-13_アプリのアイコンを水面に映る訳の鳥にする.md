# アプリのアイコンを水面に映る訳の鳥にする

- 状態：有効
- 問題：アイコンは旧名「PLaMo翻訳」の頃の「向かい合う2つの吹き出し」のままで、表示名 Mockingword（mockingbird＋word）に合っていなかった。色も、画面のデザイン言語「夜の鳥」と別に決めた藍のグラデーションだった。
- 決めたこと：作者の決定で、マネシツグミがコーラルの水面（自分の言葉＝原文）にとまり、水面に映った逆さの姿がミントの文字の行（訳）になる図柄にする。地は「夜の鳥」の紺の一色、鳥は月明かりの文字色、翼は補助の空色。映り込みの行は、逆さにして縦に縮めた鳥の輪郭に沿った長さにし、いちばん下の短い行が逆さの頭に当たる。単色版は鳥の輪郭から翼と目を抜く。図柄の意図は `app/src/main/res/drawable/ic_launcher_foreground.xml` の先頭に書いた。
- 理由：「まねる鳥」と「言葉」を、足し算ではなく1つの仕掛け（水面の映り込みが文字の行に見える）で表せ、色の役割（コーラル＝自分、ミント＝訳）も画面と同じになる。鳥はくちばしの先と頭が丸い切り抜きの安全な範囲（中心から半径33）に収まる最大の大きさにし、24dp でもくちばし・目・尾で鳥と分かることを見本で確かめた。
- 捨てた案：くちばしから声の波形が文字の行に変わる横顔（48dp で胸像の印象が残る）。向かい合ってまねる2羽（余白が多い）。翼で M を描く鳥（記号に寄りすぎ、鳥にも翻訳にも見えにくい）。丸い体の鳥（鳥らしさが消え、丸に葉が付いただけに見えた）と、翼に文字の行を引いた鳥（まとまらない）。月を背にした案（作者は水面の案を選んだ）。映り込みを鳥ごと小さく収める構図（遠目で鳥と分からない）。文字の入った吹き出しは、以前と同じく避けた。
- 再発を防ぐもの：なし（選択）
