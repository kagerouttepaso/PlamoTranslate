# CPUの動かし方を設定で切り替えスレッド数を大きいコアの数にする

- 状態：有効
- 問題：15T Pro（Dimensity 9400+）で、アプリ内の生成が0.3〜0.8トークン/秒だった。同じ端末の `llama-bench` は52〜65トークン/秒（1〜6スレッド）で、テキスト翻訳（音声認識なし）でも同じだったので、アプリ内の動かし方が原因である。既定のスレッド数は、REDMAGIC 11 Proの計測で決めた6に固定していた（[アプリ内のCPUのスレッド数を6にする](2026-11-05_アプリ内のCPUのスレッド数を6にする.md)）。
- 決めたこと：設定の画面に「パフォーマンス」（スレッド数・性能ヒント・回して待つ・スレッドの常駐・mmap・CPUだけ・CPUの版）を置き、正式な設定として残す。既定のスレッド数は、小さいコアがコアの半分以下なら大きいコアの数、そうでなければコア数−2（2〜6）にする（0.3.4）。
- 理由：作者が設定で試し、6スレッドだと小さいコア（2.4GHz）に仕事が回ってほかのスレッドが待たされると分かった。4スレッドで56〜62トークン/秒。Snapdragon以外の端末の調整にも使えるので残す（作者の判断）。
- 再発を防ぐもの：既定のスレッド数をコアの構成から求める（単体テスト `ThreadCountTest`）。`docs/設計/翻訳コア.md`「パフォーマンスの設定」。
