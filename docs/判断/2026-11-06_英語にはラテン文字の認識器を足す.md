# 英語にはラテン文字の認識器を足す

- 状態：有効
- 問題：英語の読み取りを、合成した画面だけで「中国語の認識器で十分」と判断していた。実際の英語の漫画では吹き出しの検知と翻訳が良くなかった（作者の指摘）。
- 決めたこと：ML Kitの英字（ラテン文字）の認識器を足し、英語だけの行はこれを優先する。英語を指定したときはこれだけを動かす。
- 理由：中国語の認識器は手書き風の大文字を「TITN」「PK YRO OOT RK」と読み違えた。
- 捨てた案：PP-OCRv5 mobileで英語を読む（英語の漫画ではほとんど読めなかった）。
- 再発を防ぐもの：`CLAUDE.md`「画面翻訳を変えたら評価を回す」（実際の画面の画面集で変更の前後を比べる）。
