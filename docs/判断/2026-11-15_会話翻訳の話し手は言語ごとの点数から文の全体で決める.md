# 会話翻訳の話し手は言語ごとの点数から文の全体で決める

- 状態：一部置き換え（→ [会話の話し手は区間の時系列から決め取りにいく交代と諦める交代を分ける](2026-11-15_会話の話し手は区間の時系列から決め取りにいく交代と諦める交代を分ける.md)）。文の全体を話し手の決まりの最後に置くこと、仮のカードをカードの全体の点数で分けること
- 問題：0.11.0-beta.1・beta.2 の会話で、言語の誤りと話し手の区切りの誤りを、入口ごとに直し続けていた。「誰が話しているか」を5つの入口（カードの頭・次の文の頭・文の全体・直近の監視・文の終わり）が別々の区間としきい値で判定し、識別は一番の言語の名前（99言語のうちの1つ）だけを返したので、短い区間の約35%（直近の区間79回のうち28回）が会話の外の言語か不明になった。前提は、書き起こしが安く言語も付いてくる SenseVoice（5言語）で、重い Qwen3-ASR（21言語）では崩れていた。自動の相手を覚える決まりが識別の候補を変え、識別が覚え方を変える循環もあった。
- 決めたこと：
  - 言語の識別の契約を、会話の言語ごとの点数（確率）を返す形にする。Whisper tiny は ONNX Runtime で直接動かす。SenseVoice は書き起こした言語を点数1とする。
  - 話し手は `SpeakerJudge` が「自分の言語か、それ以外か」で決め、確からしさが届かなければ決めない（前の話し手のまま）。点数を頼む入口は「話し中の区間」と「文の全体」の2つにする。
  - 文が終わったら文の全体で話し手を決め、その言語で文を書き起こす。カードの確かな話し手と違えば文の頭で区切る。すべてのモデルで文ごとに書き起こす。
  - 話し中に区切るのは、カードの話し手が確かで、継ぎ目の後ろの音声の全体も新しい言語と決まったときだけ。確かでなければ、カードの全体の点数で、話し始めの区間の誤りか交代かを分ける。
  - 言語の状態は相手不明と相手確定の2段にし、相手の発話が1回確定したら相手確定にする。相手不明の間は、モデルが聞けるすべての言語から探す（自分が日本語なら中国語、自分が中国語なら日本語を除く）。相手が分かる前の自分の発話は、相手が決まったらさかのぼって訳す。相手を選び直したら訳し直す（作者の決定）。
- 理由：PC で Whisper tiny の点数を7つの音声で測ると、文の全体では6つが正しい言語で一番だった（アラビア語だけトルコ語と僅差）。1.5秒の区間では、日本語の頭の区間を韓国語 0.95〜0.99 と判定した。短い区間は外れやすく、文の全体は確かなので、決まりの最後を文の全体に置き、区間だけでは区切らない。点数で比べれば、会話の外の言語が一番でも、会話の2言語のどちらに近いかは決められる。言語の状態を2段にしたのは、話し手が2人だから（作者の判断）。相手を誤って決めたら、利用者が選び直す。
- 捨てた案：今の5つの入口のまま識別だけを候補に絞る案（入口が減らず、同じ問いを別々に決め続ける）。相手を決める前に「仮の相手」の段を挟む案（2回の決まりが要ったのは短い区間で判定していたためで、文の全体で決めれば要らない。作者の判断で2段にした）。
- 再発を防ぐもの：`SpeechSegmenterTest` の「話し始めの区間が誤っても話し手が確かになる前は区切らず仮の言語を替える」「継ぎ目の後ろが新しい言語と決まらなければ話し中に区切らない」「自分の言語かそれ以外かで決め相手不明の間は候補の合計で比べる」、`ConversationSessionTest` の「相手が分かる前の自分の発話は原文だけを出し相手が決まったらさかのぼって訳す」。設計は `docs/設計/会話翻訳.md`「カードの区切り方」「言語の判定と訳す方向」。
