# ユーザー補助の知らせを予備の取り消しの合図にする

- 状態：有効
- 問題：画面の移動やスクロールを、画素の変化以外で知る合図を持っていなかった。
- 決めたこと：`TYPE_WINDOW_STATE_CHANGED` と `TYPE_VIEW_SCROLLED` を受け、訳している途中か訳を出していれば取り消す。移動量が0のスクロール（Discordで一覧を組み直したとき）とシステムUI（通知の引き出し）は除く。主に効くのは判定Bが遅い動く画面のモードで、通常のモードでは予備の合図として残す。
- 理由：機能テストで、Discord・漫画のアプリとも約0.1秒ごとに移動量（dy=404 など）つきで届き、窓の中身を読まない権限でも取れると確かめた。権限は増えない。実機では、通常のモードでは0.2秒ごとの判定Bの「画面が変わった」が先に取り消し（設定アプリで判定Bが22:19:35.230、最初のスクロールの知らせが35.326）、動く画面のモードではスクロールの知らせが先に取り消した。
- 再発を防ぐもの：`docs/設計/画面翻訳.md`「合図」、`docs/資料/端末の能力.md`「問い4」。
