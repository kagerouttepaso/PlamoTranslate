# GPUの読み込み中に落ちたら次の起動からCPUで動かす

- 状態：有効
- 問題：同僚のROG Phone（Snapdragon 8 Gen 3、Adreno 750）で、読み込みのたびにアプリが再起動を繰り返した。llama.cppのOpenCLはカーネルの組み立てに失敗すると `exit(1)` で終わり、`load` のCPUへのやり直しが働かない。報告の端末のログは見ていないので、`exit(1)` が原因というのは推定である。
- 決めたこと：GPUで読み込む直前に印を書き、初回の推論の後に消す（`GpuGuard`）。印が残っていたら、前回の終わり方が異常終了ならすぐ、そうでなければ2回続いたらCPUに切り替える。アプリの版か端末のビルドが変わったらGPUを試し直す。
- 理由：1回の強制停止でGPUを外さないよう、異常終了でないものは2回待つ。REDMAGICで読み込み中の強制停止を2回続けると、3回目の起動でCPUで読み込み、設定の画面に理由が出て「GPUをもう一度試す」で戻った。
- 再発を防ぐもの：単体テスト `ExitJudgeTest`（`exit(1)` を異常終了と判定する。判定は中核の `ExitJudge` にあり、不具合の記録と共通）と `GpuGuardTest`。`docs/設計/翻訳コア.md`「GPUで落ちたときの切り替え」。
