# 要件

更新日：2026-11-08

## 目的

海外旅行などの現地で、ネットワークに頼らず会話と、画面上・身の回り（看板・メニュー・ラベル）の文字を翻訳する。作者が自分のREDMAGIC 11 Proで使う個人用アプリとして作り始めた。2026-11-08から、GitHubでソースを公開し（MIT License）、リリースでAPKを無料で配る。

## 会話翻訳

- 開始ボタンを押すとマイクを入れたままにし、停止ボタンを押すまで認識と翻訳を続ける。
- 音声の言語は、音声認識（SenseVoice）が聞き分けられる日本語・韓国語・英語・中国語・広東語（2026-11-08、作者の要望「対応できる言語は全て選択できるように」で中国語・広東語を追加。翻訳モデルは53言語を訳せるが、ほかの言語は聞き取れない）。
- 発話中から認識結果と訳文を表示し、発話が終わったら確定した訳文に置き換える。Google翻訳の会話モードに近い操作感を目指す。
- 読み上げは自動ではしない。確定したカードの訳文をタップしたときだけ、訳した先の言語で読む（2026-11-08、作者の要望。「読み上げ」）。
- 自分の言語は既定の日本語のほか、韓国語・英語・中国語（簡体字）・中国語（繁体字・広東語）から選べる（2026-11-08、作者の要望）。選んだ言語は次も使う。
- 相手の言語は次の2つの方式から選べる。自分と同じ言語は選べない。
  - **自動**：相手の言語（日本語・韓国語・英語のうち自分以外）を発話ごとに判定する。自分の言語の発話は直前に判定した相手の言語へ、相手の発話は自分の言語へ訳す。中国語は自動に含めない（漢字の多い日本語を中国語と聞き違えることがあるため）。
  - **手動**：相手の言語を固定する。広東語は書き言葉の中国語（繁体字）として訳す。
- 画面は上下2分割にし、相手側の半分は180°回転して表示する。

## 画面翻訳

- 画面共有（MediaProjection）を開始しておき、浮遊ボタンを押したときだけ画面を1枚撮って翻訳する。常時キャプチャはしない。
- 原文の言語は日本語・韓国語・中国語（簡体字・繁体字）・英語を自動で判定する（既定）。浮遊ボタンの長押しで「自動・中国語・韓国語・英語」を指定することもできる（タップは翻訳）。選んだ言語は次の起動にも引き継ぐ（2026-11-05作者決定。自動判定は1ページ0.4〜0.8秒多くかかるため、指定で速くできるようにした）。
- 画面翻訳の終了は、長押しのメニューと通知から行う（トップ画面の「画面翻訳」のタイルと、クイック設定の「画面翻訳」タイルでも始め・止められる。2026-11-06）。
- 訳文は元の文字の位置に重ねて表示し、タップで原文と切り替えられる。訳の枠の背景色と文字色は元の画面にそろえる（2026-11-05作者の要望）。
- 縦書きの原文は縦書きの日本語で描く。1つの吹き出しは1まとまりで訳す（2026-11-05作者の要望）。
- 漫画・ウェブトゥーンも対象にする。吹き出しの文字、縦書き、装飾の強いフォントを読めるOCRを使う。
- 訳文の出力先は既定で日本語とし、設定で変えられる（設定は未実装で、今は日本語に固定）。

## カメラ翻訳

2026-11-06、作者の要望「カメラ画像のリアルタイム翻訳」で範囲に加えた（それまでは範囲外）。詳しい設計は `docs/設計/カメラ翻訳.md`。

- 看板・メニュー・商品のラベルにカメラを向けると、読めた文字の上に訳を重ねる。訳す先は既定の日本語のほか、PLaMoの53言語から選べる（2026-11-08、作者の要望）。選んだ言語は次も使う。
- 原文の言語は、自動のほか、文字認識（ML Kit）が読める文字で書く言語をすべて選べる（2026-11-08、作者の要望）：韓国語、中国語（簡体字・繁体字）、ラテン文字で書く25言語（英語・フランス語・ドイツ語・スペイン語・イタリア語・ベトナム語・インドネシア語など）。キリル文字・アラビア文字・タイ文字・インド系の文字の言語は、読める認識器を入れていないので選べない。選んだ言語は次も使う。
- 画面をタップすると一時停止し、そのコマの画像と訳を止めて読める。
- 文章（行を段落にまとめて訳す）と表・メニュー（1行ずつ訳す）を切り替えられる。
- 縦に持っても横に持っても、訳を持っている向きに正立させて描く。
- 縦書きは扱わない（訳は横書きで描く）。

## 読み上げ

2026-11-08、作者の要望で範囲に加えた（それまでは範囲外）。詳しい設計は `docs/設計/会話翻訳.md`「読み上げ」。

- 会話翻訳の確定したカードの訳文をタップしたとき、テキスト翻訳の訳文の右端の🔊を押したときだけ読む。自動では読まない。
- 端末の中だけで読む。読み上げのモデルはSupertonic 3を既定にし、Androidの読み上げエンジンにも切り替えられる。Supertonic 3が読めない言語（中国語）は、Androidの読み上げエンジンで読む。
- 実用の品質で読めること（作者の要望「どうせやるならちゃんとした性能として使えるやつがいい」）。

## 性能の目標

目標値は実測で見直す。見直したら理由を `docs/バックログ.md` に残す。

| 項目 | 目標 |
| --- | --- |
| 短文（約20文字）の翻訳完了 | 0.5秒以内 |
| 会話：発話中の途中訳の更新間隔 | 1秒以内 |
| 会話：発話終了から確定訳の表示 | 1.5秒以内（2026-11-06の実測は約2.5〜3秒。作者の要望で、話し終わりを無音2秒待ってから確定させているため。途中訳が先に出るので作者は待たされると感じていない。`docs/判断/2026-11-06_話し終わりの無音を2秒にする.md`） |
| 画面翻訳：ボタンから訳文の重ね表示 | 一般の画面で2秒以内、漫画1ページで4秒以内 |
| 連続稼働 | 会話翻訳を30分続けても、発熱で目標を外れない |
