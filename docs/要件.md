# 要件

## 目的

海外旅行などの現地で、ネットワークに頼らず会話と、画面上・身の回り（看板・メニュー・ラベル）の文字を翻訳する。GitHubでソースを公開し（MIT License）、リリースでAPKを無料で配る。

## 共通の前提

| 項目 | 内容 |
| --- | --- |
| 翻訳モデル | PLaMo 3 Translate。0.8B（`plamo-3-translate-0.8b-Q4_K_M.gguf`、573MB）と2B（`plamo-3-translate-2b-Q4_K_M.gguf`、1.8GB）から選ぶ |
| 推論 | 端末内のllama.cpp（Snapdragonの端末はGPU、それ以外はCPU）。訳す文字・画像・声を端末の外へ送らない。通信するのは、初回起動時に選んだモデル（翻訳・音声認識・読み上げ）と必須のモデルをまとめて取るダウンロード、設定の画面で別のモデルを選んだときの追加のダウンロード、設定で「更新を確認」「ダウンロードして更新」を押したとき（GitHubのリリース）と、文字の認識に使う ML Kit が利用の指標（画像や文字は含まない）を Google へ送るときだけ。通信することは「このアプリについて」とプライバシーポリシー（`PRIVACY.md`）で利用者に知らせる |
| モデルの選び方 | 翻訳・音声認識・読み上げのモデルは、利用者が初回の「モデルの準備」で選んで取る（画面の初期選択は小さい方）。後から設定の画面で替えられる。アプリがどれかに決め打ちしない |
| 対象端末 | 性能の目標は REDMAGIC 11 Pro（NX809J、Snapdragon 8 Elite Gen 5、Android 16）で測る。配る端末は、Android 13以上・64bit（arm64）なら動く作りにする |
| 利用者の言語 | 日本語。訳文の既定の出力先は日本語 |
| ライセンス | PLaMo Community License。学習・趣味などの個人利用と非商用利用は、事前登録なしで無料（モデルのページの記載）。アプリを無料で配る使い方もこの範囲と判断している。重みはアプリに同梱せず、使う人の端末が公式の配布元から取る |

## 機能ごとの優先順位

要件どうしがぶつかったときは、上を優先する。下の項目のために上の項目を損なう変更は、作者の判断なしに入れない。機能によって、使う場面といちばん困る失敗が違うので、並びは機能ごとに決める（`docs/判断/2026-11-16_要件の優先順位を機能ごとの場面から決める.md`）。

どの機能でも最上位は **外へ出さない**（訳す文字・画像・声を端末の外へ送らず、正式版のログに原文・訳・話した言葉を書かない）。端末の中だけで動くことがこのアプリの前提で、どの機能も他人の声・他人とのやり取り・その場の映像を扱う。以下は、その次からの並び。

### 会話翻訳

端末を2人の間に置き、言葉の通じない相手と話す。いちばん困るのは、話し手か言語を取り違え、相手の発言を自分の発言として、または逆向きに訳すことで、会話が食い違っても利用者は気づきにくい。

1. **話し手と言語を取り違えない**：確かでないときは決めずに待ち、自動で決めた相手の言語は画面に出して、利用者が選び直せるようにする。
2. **会話を途切れさせない**：話している最中から、途中の文字と途中訳を出し続ける。
3. **読める区切り**：1枚のカードは話した人の1〜2文で、文の途中で切らず、断片を作らない。
4. **確定訳の速さ**：交代や話し終わりの確定は、1〜2秒遅れてよい。

### 画面翻訳

自分の端末で、ほかのアプリ（漫画・SNS・ゲーム）を操作しながら、その上に訳を重ねて読む。いちばん困るのは、訳の表示が下のアプリの操作を妨げること。

1. **下のアプリの操作を妨げない**：訳の枠は触れた操作を下のアプリへ通し、訳している途中に触れたら処理を取り消す。
2. **古い訳・別の場所の訳を出さない**：画面が変わったら訳を消す。別の吹き出し・メッセージの訳を付けない。
3. **原文の位置と範囲に収める**：訳は原文の位置・向き・吹き出しやメッセージの範囲に描き、縦書きは縦書きで描く。
4. **読みやすい訳語**：「訳語の方針」に従う。
5. **速さ**：「性能の目標」の値。見えている部分から先に訳す。

### カメラ翻訳

旅先で看板・メニュー・ラベルにカメラを向け、その場で読んで、何を注文するか・どちらへ行くか・何を買うかを決める。いちばん困るのは、読み違えた原文の訳を正しい訳として見せること（食材や薬のラベルでは実害につながる）。

1. **読み違えた原文を訳さない**：読み取りがそろった行だけを訳す。表示が安定していても、正しい文が出ることを先にする。
2. **表示の安定**：枠と段落の区切りがちらつかず、同じ文の訳が出たり消えたりしない。
3. **速さ**：見ている文から待たされずに訳がそろう。
4. **電池**。

### テキスト翻訳

入力した文や貼り付けた文を、内容を確かめながら訳す。

1. **誤訳しない**。
2. **読みやすい訳語**：「訳語の方針」に従う。
3. **速さ**。

## 訳語の方針

- 文章・吹き出し・会話は、文脈に合った自然な日本語にする。会話翻訳は話し言葉で訳す。
- 製品名・ボタン名・モデル名のような短い英字の項目は、モデルが原文のまま返したものを受け入れる（`docs/設計/翻訳コア.md`「生成の点検」）。
- 画面の文言・README・プライバシーポリシーは、技術者でない利用者に通じる一般的な名称で書く（`docs/設計/アーキテクチャ.md`「書き方の決まり」）。

## 会話翻訳

- 開始ボタンを押すとマイクを入れたままにし、停止ボタンを押すまで認識と翻訳を続ける。
- 話せる言語は、選んだ音声認識モデルが聞ける言語のうち、PLaMo が訳せるもの。SenseVoice Small は日本語・韓国語・英語・中国語・広東語、Qwen3-ASR 0.6B はそれにロシア語・フランス語・ドイツ語・スペイン語・ヒンディー語などを足した21言語を聞く。
- 発話中から認識結果と訳文を表示し、発話が終わったら確定した訳文に置き換える。
- 読み上げは自動ではしない。確定したカードの訳文をタップしたときだけ、訳した先の言語で読む（「読み上げ」）。
- 自分の言語は、話せる言語から選ぶ（既定は日本語）。選んだ言語は次も使う。
- 相手の言語は次の2つの方式から選べる。自分と同じ言語は選べない。
  - **自動**：相手の言語が分かるまでは、自分の発話を原文だけで出し、相手の言語が決まったらさかのぼって訳す。決まった相手の言語は画面に出し、利用者が選び直せる。自分が日本語のときは中国語を、自分が中国語のときは日本語を、自動では探さない（漢字の多い日本語と中国語を聞き違えるため）。
  - **手動**：相手の言語を固定する。広東語は書き言葉の中国語（繁体字）として訳す。
- 表示は対面（上下2分割にし、相手側の半分は180°回転する）と1画面から選べる。

## 画面翻訳

- 画面共有（MediaProjection）を開始しておき、フローティングボタンを押したとき、または自動で訳す設定では画面が落ち着いたときに、画面を撮って翻訳する。
- 原文の言語は日本語・韓国語・中国語（簡体字・繁体字）・英語を自動で判定する（既定）。フローティングボタンの長押しのメニューで言語を指定することもできる（タップは翻訳）。指定できるのは、文字認識が読める文字で書く言語すべて（中国語の簡体字・繁体字、韓国語、ラテン文字で書く25言語。カメラ翻訳の原文と同じ）で、中国語・韓国語・英語はメニューの行から、ほかは「他の言語」から選ぶ。選んだ言語は次の起動にも引き継ぐ。
- 画面翻訳の終了は、長押しのメニューと通知から行う。トップ画面の「画面翻訳」のタイルと、クイック設定の「画面翻訳」のタイルでも始め・止められる。
- 訳文は元の文字の位置に重ねて表示し、訳の枠の背景色と文字色は元の画面にそろえる。訳の枠は触れた操作を下のアプリへ通し、訳の表示のオン・オフはフローティングボタンで切り替える。訳の消え方（画面が変わったら消す・触れるまで残す）は場面で選べる。
- 縦書きの原文は縦書きの日本語で描く。1つの吹き出しは1つのブロックとして訳す。
- 漫画・ウェブトゥーン・チャット・ゲームを対象にする。吹き出しの文字、縦書き、装飾の強いフォント、白縁の文字を読めるOCRを使う。
- 訳文の出力先は既定で日本語とし、設定で変えられる（設定は未実装で、今は日本語に固定）。

## カメラ翻訳

詳しい設計は `docs/設計/カメラ翻訳.md`。

- 看板・メニュー・商品のラベルにカメラを向けると、読めた文字の上に訳を重ねる。訳す先は既定の日本語のほか、PLaMoの53言語から選べる。選んだ言語は次も使う。
- 原文の言語は、自動のほか、文字認識（ML Kit）が読める文字で書く言語をすべて選べる：韓国語、中国語（簡体字・繁体字）、ラテン文字で書く25言語（英語・フランス語・ドイツ語・スペイン語・イタリア語・ベトナム語・インドネシア語など）。キリル文字・アラビア文字・タイ文字・インド系の文字の言語は、読める認識器を入れていないので選べない。選んだ言語は次も使う。
- 画面をタップすると一時停止し、そのコマの画像と訳を止めて読める。
- 文章（行を段落にまとめて訳す）と表・メニュー（1行ずつ訳す）を切り替えられる。
- 縦に持っても横に持っても、訳を持っている向きに正立させて描く。
- 縦書きは扱わない（訳は横書きで描く）。

## 読み上げ

詳しい設計は `docs/設計/会話翻訳.md`「読み上げ」。

- 会話翻訳の確定したカードの訳文をタップしたとき、テキスト翻訳の訳文の右端の🔊を押したときだけ読む。自動では読まない。
- 端末の中だけで読む。読み上げは Supertonic 3 と Androidの読み上げエンジンから選べる。Supertonic 3が読めない言語（中国語）は、Androidの読み上げエンジンで読む。
- 実用の品質で読めること。

## 性能の目標

目標値は実測で見直す。見直したら理由を判断の記録に残す。今の測った値は、各機能の設計書の「性能の目安」にある。

| 項目 | 目標 |
| --- | --- |
| 短文（約20文字）の翻訳完了 | 0.5秒以内 |
| 会話：発話中の途中訳の更新間隔 | 1秒以内 |
| 会話：発話終了から確定訳の表示 | 1.5秒以内（今は話し終わりの無音を待ってから確定させるので、これより遅い。途中訳が先に出る。`docs/判断/2026-11-13_会話翻訳の長い発話は文の終わりで区切り話し終わりの間を3秒にする.md`） |
| 画面翻訳：ボタンから訳文の重ね表示 | 一般の画面で2秒以内、漫画1ページで4秒以内 |
| 連続稼働 | 会話翻訳を30分続けても、発熱で目標を外れない |

## 範囲外

- クラウドの翻訳・音声認識への切り替え
- Google Playでの配布（配布はGitHubのリリースのAPKだけにする）
