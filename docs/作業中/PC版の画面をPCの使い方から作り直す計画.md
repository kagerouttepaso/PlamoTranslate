# PC版の画面をPCの使い方から作り直す計画

## 望む状態

- PC版の画面は、PCで使う場面（机で1人が大きなウィンドウで見る。キーボードとマウス。PCの再生音を訳す）から決める。Android版・ブラウザ版で作り込んだ見せ方と操作は引き継ぎ、Androidの持ち方が理由のもの（対面で2人が1台を囲む）は持ち込まない。
- PDF翻訳は、ブラウザ版の PDF翻訳（リポジトリ `Mockingword-browser` の文書「12_PDFの翻訳」）と同じ体験にする。ビューアで読み、「翻訳を開始」で訳し、訳したページは原文の文字を消して訳文を書いたPDFのページに差し替わる。見えているものを保存できる。

## 今の問題

| 機能 | 今のPC版 | 引き継ぐもの |
| --- | --- | --- |
| 会話翻訳 | 話し中・書き起こし待ち・確定のカードが同じ見た目。会話中は言語を変えられない。「話す人（自動・自分・相手）」と「対面」がある。区切るボタンが小さなボタンの列に並ぶ | Android の `LiveCard`（枠線・「● 自分・英語」・音量のバー・経過秒）と `WaitingCard`（細い枠・「⏳ 書き起こし中」）、確定したカードの色と時間の表示。会話中に自分・相手の言語を選び直せる。区切るボタンを1つの強い操作として中央に大きく置き、周りの輪をマイクの音量にする |
| PDF翻訳 | 開くと訳し始め、原文の絵の上に訳を重ねる。拡大縮小・並べ方・見出し・リンク・戻る/進む・保存・中止・原文/訳文の切り替えが無い。表のセルが訳されない | ブラウザ版の PDF翻訳の全部（下の「PDF翻訳」） |
| テキスト翻訳 | 項目を縦に並べただけ。訳した速さの表示が無い | Android 版の配置と、訳の下のかかった時間・速さの小さな表示 |
| 全体 | 機能ごとに項目を足した画面 | `docs/設計/デザイン言語.md` の色の役割・強い色は1画面に1つ・説明の副題を添えない |

原因は、PC版の画面を「Android版にある項目を移す」「元の計画の PDF の画面（訳を重ねる）を作る」で決め、PCで使う場面とブラウザ版で作者と詰めた PDF翻訳の決定を設計の入力にしなかったこと。

## 方針

### 会話翻訳

- 画面は、上に「マイク / PCの音」の切り替え、真ん中にカードの一覧、下に操作の帯。操作の帯は左に「開始・停止」と「自分 ▾」「相手 ▾」、中央に区切るボタン、右に「記録 ▾」（保存・コピー・消去）と翻訳モデル。状態の1行は Android の文言にそろえる。
- 区切るボタンはスペースキーでも押せる（文字を入力する欄に注目が無いとき）。
- 自分・相手の言語は会話中も選び直せ、次の発話から効く。相手の言語の「自動」は、見つけた言語を「英語（自動）」のように出す。
- 話し手は話した言語で決める（Android と同じ）。誤りはカードを入れ替えて直す。「話す人」の切り替えと「対面」は無くす。
- PCの音は、原文の言語と訳す先、字幕のウィンドウ。カードは同じ見せ方。

### テキスト翻訳

- Android 版の配置（言語の帯・原文・訳文・操作）をPCの横長のウィンドウに合わせ、原文と訳文を左右に並べる。訳の下に、かかった時間と速さを小さく出す。

### PDF翻訳

ブラウザ版の作りをPCへ移す。PDFium は Windows の DLL（固定版）をそのまま使い、編集の API も JNI で呼ぶ。

- **ビューア**：PDFium で描いたページを縦に続けて出す。幅に合わせる・高さに合わせる・100%・拡大・縮小、1ページ・見開き（奇数が左）・見開き（表紙を単独）。左に見出しの欄（しおりのツリー、開閉を覚える）。文書の中のリンクで移り、「← 戻る」「進む →」・Alt+←/→・マウスの戻る/進むボタンで行き来する。外へのリンクは既定のブラウザーで開く。表示の設定は覚える。
- **翻訳**：開いただけでは訳さない。「翻訳を開始」で、見ているページから距離順に訳す。訳し終えた文から段落に重ね、残りの原文を薄く表示する。ページの段落がそろったら、そのページを訳したPDFのページに差し替える。「翻訳を中止」「翻訳を再開」、「原文」「訳文」の切り替え。
- **訳したPDF**：原文の写しから始め、訳す段落の文字のオブジェクトを消して訳文を書く。訳さない文字（箇条書きの記号・目次の番号と点線）は置き直す。リンクは訳文の位置へ移す。埋め込みのフォームの中の文字は背景色で覆って上に書く。収まらなければ0.7倍まで縮める。行の折り返しと禁則はブラウザ版と同じ。
- **保存**：「訳したPDFを保存」で、訳している途中でも、見えている訳したPDFを保存する。使った字形だけを残すようにフォントを縮め、しおりの見出しを訳文にする。
- **判断は中核**：段落の組み立て（セグメント・段落・表のセル・ヘッダーとフッター・目次の点線）、訳す順番とまとめ方（`chunk`、見出しと第1段落を先、短い項目はまとめて送る）、折り返しと禁則は `core-pipeline` に置き、ブラウザ版の規則と同じ結果になることを試験で確かめる。今の `PdfLayout`・`PdfTranslationPlan` はこの規則で書き直す。
- **文字の選択と検索**：表示しているページ（原文、または訳したPDF）の文字を PDFium のテキストページから取り、ドラッグで選んでコピーできる。上の帯の検索の欄（Ctrl+F）で、表示している文書の中を探し、見つかった所を光らせて前後へ移る。

- 作者の手元の Kvaser の取扱説明書2冊で、表・目次・リンク・しおり・埋め込みのフォームのページが、ブラウザ版と同じく読めるか。
- 会話翻訳で、話し中・書き起こし待ち・確定のカードが見分けられるか、会話中に相手の言語を変えて次の発話から効くか。
- 速さの計測は、作者の指定した時間に1回だけ行う。
