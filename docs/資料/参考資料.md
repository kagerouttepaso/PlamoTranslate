# 参考資料

外部の資料の場所と、何が書いてあるかの一言をまとめる。使っている版は `docs/現在地.md`「固定した版」、取得元のURLの正本は `app/src/main/java/app/plamotranslate/models/ModelCatalog.kt` にある。

## 翻訳モデル

- PLaMo 3 Translate 0.8B のモデルカード（PFML3の仕様、対応言語、ライセンス）：https://huggingface.co/pfnet/plamo-3-translate-0.8b
- PLaMo 3 Translate 0.8B GGUF（ファイル一覧、llama.cppでの実行例、量子化の説明）：https://huggingface.co/pfnet/plamo-3-translate-0.8b-GGUF
- PLaMo 3 Translate 2B GGUF（2Bの配布元）：https://huggingface.co/pfnet/plamo-3-translate-2b-GGUF
- PFNの技術ブログ（モデルの開発の経緯と性能）：https://www.preferred.jp/ja/blog/tech/plamo-3-translate-weight-release
- PLaMo Community License（条文。アプリから開く）：https://plamo.preferredai.jp/info/plamo-community-license-ja

## 推論ランタイム

- llama.cpp：https://github.com/ggml-org/llama.cpp
  - `third_party/llama.cpp/docs/android.md`：Androidでのビルド
  - `third_party/llama.cpp/docs/backend/OPENCL.md`：OpenCL（Adreno）のバックエンド
  - `examples/llama.android`：JNIとGradleの構成の参考実装
- PLaMo 3 Translate 0.8B とカメラのOCRを組んだAndroidアプリ（参考実装）：https://github.com/hassaku918/plamo-translate-app

## 音声認識

- sherpa-onnx（音声認識と読み上げの実行）：https://github.com/k2-fsa/sherpa-onnx
  - リリース（AAR、`asr-models` タグの音声認識モデルと `silero_vad.onnx`）：https://github.com/k2-fsa/sherpa-onnx/releases
- SenseVoice Small の sherpa-onnx 向けの書き出し（アプリの取得元）：https://huggingface.co/csukuangfj/sherpa-onnx-sense-voice-zh-en-ja-ko-yue-2024-07-17
- SenseVoice（モデルの元。FunAudioLLM）：https://github.com/FunAudioLLM/SenseVoice
- FunASR のライセンス（SenseVoiceのモデルの条件）：https://github.com/modelscope/FunASR?tab=readme-ov-file#license
- Silero VAD：https://github.com/snakers4/silero-vad

比べる候補（`docs/バックログ.md`）：

- sherpa-onnx の Qwen3-ASR 対応：https://k2-fsa.github.io/sherpa/onnx/qwen3-asr/index.html
- Nemotron 3.5 ASR（INT4、チャンク長ごとのエンコーダー）：https://huggingface.co/jeffpeng3/nemotron-3.5-asr-multi-encoder-int4
- Nemotron 3.5 ASR（onnx-community、INT4）：https://huggingface.co/onnx-community/nemotron-3.5-asr-streaming-0.6b-onnx-int4
- 韓国語の音声認識の比較（SenseVoice・Qwen3-ASR・Zipformer のCER）：https://github.com/JDeun/LangTextFlow/issues/110

## 縦書きの組版
