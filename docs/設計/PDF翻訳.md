# PC版の PDF 翻訳

PDF 翻訳の段落抽出、依頼順、訳文の配置は、ブラウザー版と共通の判断規則を `core-pipeline` に置く。`PdfSession` が表示中のページを基準に翻訳を頼み、段落の訳がそろったページを Windows 側へ渡す。翻訳は `TranslationStream`、PDF の読み取りと書き込みは PDFium を通す。

## 段落の組み立て

`PdfParagraphs.page` は PDFium のテキストページを `PdfPageText` で受け取る。座標は左下原点のポイント。文字ごとに Unicode、テキストページの文字番号、原点、外接矩形、フォント名、太さ、色、リンク注釈の番号を受け取る。文字サイズには、フォントの大きさに `FPDFText_GetMatrix` の縦の拡大率を掛けた値を使う。テキストオブジェクトはページからの番号列で表し、Form XObject の中では親から順に番号を並べる。

1. PDFium の文字順のまま、基線、前の文字との距離、文字サイズでセグメントを分ける。基線が近く小さい上付き文字は直前のセグメントに含める。生成された改行は捨て、生成された空白は残す。目次の見出しと点線は別のセグメントにする。
2. セグメントを上から下、同じ基線なら左から右に並べる。段落の左端がそろい、行送りの範囲内で、太さとサイズが近い行をつなぐ。同じ行に別のセグメントがあるセルは別の段落になる。箇条書きは項目で分け、記号を残す。行末のハイフンは PDFium の判定を使って除き、次の行の語とつなぐ。
3. リンク、段落の標準と異なる太字、等幅の文字はマーカーで表す。段落全体のリンクは段落の属性にする。PDFium が Unicode に変換できない文字の並びも、フォント名にかかわらず等幅の文字と同じ種類のマーカーで表す。その字形を参照するために、元の文字番号・座標・字送りを保持する。PDFium がこのとき返す文字コードは Unicode として翻訳に渡さない。
4. `PdfParagraphs.classify` は全ページの段落を見て、連続する文字が2字以上ない段落、かなを含む段落、および丸めた基線と原文が異なる3ページ以上で一致する段落を依頼から外す。繰り返しを判定するときは数字列を同一視する。

`PdfParagraph` は行ごとの基線と文字範囲、段落全体と訳す文字の外接矩形、文字ごとの翻訳対象フラグ、テキストオブジェクトの番号列を持つ。書き込み側はページ内の全段落を使い、消すオブジェクトを共有する箇条書きの記号、目次の点線や番号、訳す対象外の段落を置き直せる。

## 訳す順番と確定

Windows のビューア（[ビューア](#ビューア)）がページの描画、表示倍率、並べ方を管理し、表示の中心にあるページを `PdfEvent.Page` で `PdfSession` に渡す。中核は翻訳の開始を受け取ると、ビューアの表示状態にかかわらず、繰り返すヘッダーとフッターを判断するために全ページから段落を集める。開き直しの世代番号と翻訳バッチの番号で、以前の文書や中止した依頼からの応答を捨てる。

`PdfTranslationPlan` は空いた翻訳枠を、表示中のページからの距離順に使う。表示中のページより前のページへの距離は1.5倍にする。移動したときは、空いた枠から新しい表示位置で選ぶ。状態行には、処理中の段落を含む全ページのうち、この距離で表示位置に最も近いページを示す。

- ページ内では、原文の文字数が最も多いフォントサイズを本文の基準にする。サイズか太さで見出しを判定し、見出しと節の第1本文段落を優先する。表のセルなどの短い項目は本文から分ける。
- 本文と短い項目を各8行・400字までにまとめる。上限を超える1段落は単独にする。空き枠があれば本文のバッチを分割し、短い項目は同じ依頼に保つ。
- 同じ原文の依頼と確定訳は文書全体で共有する。訳がそろったページは `WritePage` を1回発行し、書き込み結果を受けて表示に渡せる状態にする。原文と同じ訳や空の訳は原文を残す。中止では全バッチと途中表示を取り消し、再開は未確定分から続ける。

Windows の `PdfPresenter` は確定・途中・失敗を1本の `TranslationStream` から購読する。途中訳は文末までを使い、バッチ内で改行まで届いたラベルも表示できる。行対応が崩れたら該当する途中訳を取り下げる。長文を分けた場合は、先頭のチャンクを途中表示に使う。契約は [翻訳コアの「命令と購読」](翻訳コア.md#命令と購読) を参照。

## ビューア

ブラウザー版で pdf.js が受け持つ表示は、Windows では `PdfScreen`（帯・見出しの欄・検索）と `PdfPages`（ページの描画と操作）が PDFium の文書から描く。Compose に依存しない決まり（並べ方 `PdfSpread`、拡大率 `PdfZoom`・`PdfScale`、戻る/進む `PdfHistory`、検索結果 `PdfSearch`）は `desktop/pdf/PdfView.kt` に置く。

- 開いた PDF は読むだけにし、「翻訳を開始」で訳し始める。中止・再開・やり直しは `PdfEvent.Start`・`Stop`・`Retry` を送るだけにする。
- 画面は `PdfPresenter.state` を購読する。翻訳状態、原文と訳文の版、表示モード、見出し・履歴・選択・検索結果、差し替え中のページをまとめて受け取り、表示範囲と描画完了を Presenter に知らせる。
- PDFium から状態・見出しの移動先・履歴・検索結果までは、ページを 0 始まりの添字で扱う。状態行とページ欄は `PdfPageNumber` で 1 始まりの番号に変換し、ページ欄への入力は同じ部品で添字に戻す。
- 最初の文が届くまでは、訳している段落の原文に背景色を不透明度 0.45 で重ねる。文が届いたら原文の文字の外接矩形を背景色で覆い、訳文と、まだ訳していない原文を描く。残す原文は訳文と同じ文数だけ先頭から除き、段落の空きに入る分を不透明度 0.55 で表示する。同じ原文が複数箇所にあっても、文字色・背景色・太字は各段落のものを使う。
- 確定訳は、新しい版のページ画像を描くまで元の画像の手前に残す。画像を差し替えたら、確定訳の重ね表示を 0.25 秒で消す。画面外の書き込み済みページ、原文への切り替え、中止、文書を開き直す操作ではすぐに重ね表示を消す。
- 連続スクロールで、ページを「1ページずつ」「見開き」「見開き（表紙を単独）」に並べる。拡大率は幅に合わせる・ページ全体・25〜400% の段階で、Ctrl+ホイールと Ctrl+=/−/0 でも変える。表示の中心にある行の先頭ページを `PdfPresenter.page` に渡す。
- ページ操作の帯は、テキスト翻訳の帯と共通の `DesktopToolbar` を使う。見出し欄を除いた幅に収まらない操作は、並び順とラベルを保って次の行に送る。縮小・倍率・拡大は同じ行に置く。
- 見出しの欄は原文の見出しを並べ、訳文を見ているときは `PdfState.titleTranslation` の訳で出す。見出しと文書内リンクの移動は戻る・進むの履歴に積み、Alt+←/→ とマウスの戻る・進むボタンで戻れる。外部リンクは http・https・mailto だけを既定のブラウザー・メールで開く。
- 文字の選択はドラッグの始点と終点に近い文字を `characterAt` で求め、その間を `selection` で取る。Ctrl+C でコピーする。検索（Ctrl+F）は表示している版の文字を、表示中のページから順に全ページで探す。
- 描いた画像は原文・訳文、ページ、幅で区別し、24枚まで保持する。一度書いたページは後続の版でも中身が同じなので、取得済みの画像を使う。1枚は長辺 4096 画素・1200 万画素までに抑え、画面には引き伸ばして出す。
- スクロールバーは暗い背景でも見えるよう、画面の文字の色で常に描く。
- 拡大率・並べ方・見出しの欄の開閉は `pdf-view.properties` に保存する。「訳した PDF を保存」は、訳している途中でも書き込み済みのページを入れて保存する。

## 訳文の配置

`PdfLayout.paragraphGeometry` は原文の段落幅、基線、行送りと、下にある横位置の重なる段落から、訳文の範囲を決める。フォーム内では訳す文字の外接矩形に幅を制限する。`planParagraph` は Windows 側から渡された字幅の計測関数を使い、英数字の並びを保ち、日本語は1文字ずつ折り返す。行頭禁則はぶら下げ、行末禁則は次の行へ送る。

訳文の最後の基線が段落の下端を越える場合は、文字サイズと行送りを同じ割合で0.05刻み、最小0.7倍まで縮める。縮めても収まらない場合は最小倍率で配置する。途中表示に原文の残りを加えるときは、訳文の配置を先に決め、空きに入る原文だけを続ける。途中表示と書き込みはこの配置の基線と位置を使う。翻訳開始時に Noto Sans JP の読み込みを始め、取得中は代替フォントで表示し、取得後に標準・太字の同じフォントで配置し直す。通常の文字は同じ太さとリンクの連続をまとめる。

Unicode が分かる等幅の文字は、マーカー内の訳を使わず、原文の文字列を訳文と同じ埋め込みフォントで描く。Unicode に変換できない字形の並びは、元の字送りを使い、途中で折り返さず配置する。PDFium のページ書き出しは Type 3 のテキストを再生成できないため、元フォントと文字コードで描画してから、該当の字形だけを透過画像として埋め込む。この字形は訳文で検索・選択できない。これらの字形を含む段落は途中訳で覆わない。確定訳で対応するマーカーが欠落または重複した場合も原文を残す。

`PdfBackground` は原文ページの画素から、訳す文字の外接矩形内で文字色に近い画素を除いた最頻色を選ぶ。最初にそのページの段落を訳すときに採色し、フォームを覆う色と途中表示の背景色に共用する。回転したページの表示のように座標を画素へ直すのが表示側の場合は、画素の範囲を渡す。

原文の文字オブジェクトをページから取り除く場合、PDFium は元の描画命令を再生成する。再生成で ICC プロファイルなどの色指定が落ちないように、ページ直下に残るパスと文字の単色の塗り・線を、PDFium が返す RGB 値と不透明度で設定し直す。既定色の黒、パターンとして取得できた色、フォーム内の描画命令は設定し直さない。この処理で色を設定し直したオブジェクトは、原文の文字がない描画ストリームに属していても再生成の対象になる。パターンやグラデーション自体の保存は保証しない。[判断の記録](../判断/2026-11-22_ページ再生成の前に単色をRGBで設定し直す.md)

`PdfTitles` はマーカー・空白・大文字小文字を正規化した見出しをキーに、本文中の確定訳をしおりと対応させる。`PdfState.titleTranslation` はビューアが PDFium から読んだ見出しに対応する確定訳を返す。リンク注釈の移動、フォント埋め込みと部分化、書き換えたページの描画と保存は Windows 側の責務である。

## 永続キャッシュ

`DesktopPdfCache` は `PersistentCache` の Windows 実装で、`%LOCALAPPDATA%\Mockingword\cache\pdf-translations\v1` に保存する。翻訳の範囲とチャンクの原文をハッシュにし、ファイルの中身には訳とモデルの品質を残す。同じ条件と品質なら、アプリを閉じても保存済みの訳を使う。空訳と原文の写しはファイルに保存しない。設定でキャッシュを消去すると、保存済みの訳を消して世代を進め、消去前に開始した翻訳の書き戻しを除外する。

## 読み取りの限界

横書きの文字の順序と座標から段落を推定する。文字のないページは原文画像を表示する。PDFium が Unicode に変換できない文字、回転した文字、装飾された字間、複雑な図や表では抽出結果が原文の読み順と異なることがある。
