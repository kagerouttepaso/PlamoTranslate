# PC版の PDF 翻訳

PDF の原文を先に表示し、表示中のページから段落単位で訳す。ページ表示に翻訳モデルは要らない。読み取れる文字がないページも、画像としては読める。

## ページと段落

PDFium はページの大きさ、指定した画素数で描いた画像、文字ごとの外接矩形を返す。外接矩形はページ左上を原点に正規化し、画像と同じ座標で扱う。`DesktopPdfReader` は同じ PDF に対する処理を入出力用のコルーチンで直列に行う。表示倍率を変えたら描き直すが、大きなページでは画像の画素数に上限を設ける。

`core-pipeline` の `PdfLayout` は、横位置と縦位置から行を組み、空き幅で行内の段やセルを分ける。連続する本文の行は段落にまとめ、箇条書きの項目や「Figure 1:」のような説明は段落を分ける。本文の段組みは左の段から読み、表とみなした行は左から右へセルごとに訳す。原文の行の矩形は段落に残す。

## 表示と先読みの順番

`PdfSession` が状態遷移と処理の発行を一か所にまとめる。最初のページは描画してから文字を取り出し、表示中のページの画像をそのページの翻訳より先に渡す。画像は次の2ページ分、訳は次の1ページ分まで先読みする。`PdfTranslationPlan` は、現在のページの未訳段落が終わってから次のページを選ぶ。移動で不要になった翻訳は取り消し、前のファイルや言語の結果が遅れて届いても表示に混ぜない。

## 読み取りの限界

文字の座標をもとにした横書き用の処理なので、罫線、結合セル、縦書き、回転した文字の読む順は復元しない。PDFium が Unicode に変換できない字は置換文字になり、装飾された字間や図中の文字も元どおりにならないことがある。画像だけの PDF の OCR と、パスワード付き PDF の解除には対応していない。
